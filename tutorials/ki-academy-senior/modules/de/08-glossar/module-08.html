Das KI-Wörterbuch

Alle Begriffe, die Sie kennen müssen – verständlich erklärt

Glossar durchsuchen
A B C D E F G H I K L M N P Q R S T U V W Z

A

Algorithmus

Eine feste Regel oder Anleitung, wie ein Problem gelöst wird. Wie ein Kochrezept: Schritt für Schritt führt der Algorithmus zum Ergebnis.

Grundlagen

API

Application Programming Interface – die "Sprache", mit der verschiedene Programme miteinander kommunizieren. Wie ein Übersetzer zwischen zwei Software-Systemen.

Technik

Assistent

Ein KI-System, das Aufgaben ausführt oder Fragen beantwortet. ChatGPT, Claude oder Google Assistant sind Beispiele für KI-Assistenten.

Anwendung

B

Bias

Voreingenommenheit oder Verzerrung. KI-Systeme können Vorurteile aus ihren Trainingsdaten übernehmen – z.B. stereotype Geschlechterrollen.

Ethik

Bot

Ein automatisierter Computerprogramm, das Aufgaben ohne menschliches Zutun erledigt. Chatbots führen textbasierte Gespräche.

Anwendung

C

Chain of Thought

"Gedankenkette" – eine Technik, bei der die KI Schritt für Schritt denkt und ihre Überlegungen ausgibt. Führt zu besseren Ergebnissen bei komplexen Aufgaben.

Prompting

Chatbot

Ein Computerprogramm, das textbasierte Gespräche führt. Moderne Chatbots wie ChatGPT nutzen große Sprachmodelle für natürliche Dialoge.

Anwendung

Context Window

Das "Gedächtnis" der KI – wie viel Text sie gleichzeitig verarbeiten kann. GPT-4 kann ca. 25.000 Wörter, Claude bis zu 100.000.

Technik

D

Deep Learning

Eine fortgeschrittene Form des maschinellen Lernens mit künstlichen neuronalen Netzen. Die Basis moderner KI-Systeme wie GPT.

Grundlagen

DALL-E

Ein KI-System von OpenAI, das Bilder aus Textbeschreibungen erzeugt. Das "A" steht für Salvador Dalí, "E" für WALL-E.

Bild-KI

E

Embedding

Die Umwandlung von Text in mathematische Vektoren, damit die KI Bedeutungen verstehen und vergleichen kann.

Technik

F

Few-Shot Learning

Die Fähigkeit einer KI, aus wenigen Beispielen zu lernen. Beim Prompting: mehrere Beispiele zeigen, wie die Ausgabe aussehen soll.

Prompting

Fine-Tuning

Das Nachtrainieren eines KI-Modells für spezifische Aufgaben. Macht das Modell besser in einem bestimmten Bereich.

Technik

G

Generative KI

KI, die neue Inhalte erzeugt: Texte, Bilder, Musik, Code. Im Gegensatz zu analysierender KI, die nur Daten auswertet.

Grundlagen

GPT

Generative Pre-trained Transformer – die Technologie hinter ChatGPT. Ein großes Sprachmodell, das Texte vorhersagen und generieren kann.

Grundlagen

Guardrails

Schutzmechanismen, die verhindern, dass KI schädliche oder unangemessene Inhalte erzeugt. Wie Sicherheitsgurte für KI-Antworten.

Sicherheit

H

Hallucination

"Halluzination" – wenn KI falsche Informationen erfindet, aber selbstsicher präsentiert. Eine der größten Herausforderungen bei LLMs.

Kritisches Denken

I

Inference

Das Anwenden eines trainierten KI-Modells auf neue Daten. Wenn Sie mit ChatGPT chatten, läuft gerade Inference.

Technik

K

KI

Künstliche Intelligenz – Computerprogramme, die Aufgaben ausführen, die normalerweise menschliche Intelligenz erfordern: Lernen, Problemlösen, Sprachverständnis.

Grundlagen

L

LLM

Large Language Model – ein großes Sprachmodell, das auf riesigen Textmengen trainiert wurde. GPT-4, Claude und Gemini sind LLMs.

Grundlagen

M

Maschinelles Lernen

Machine Learning (ML) – Computer lernen aus Daten, ohne explizit programmiert zu werden. Die Grundlage moderner KI.

Grundlagen

Midjourney

Ein populäres KI-Tool zur Bildgenerierung. Bekannt für besonders ästhetische und künstlerische Ergebnisse.

Bild-KI

Multimodal

KI, die verschiedene Datentypen verarbeiten kann: Text, Bilder, Audio, Video. GPT-4V kann Bilder "sehen" und beschreiben.

Technik

N

Neuronales Netz

Ein Computermodell, inspiriert vom menschlichen Gehirn. Millionen künstlicher "Neuronen" verarbeiten Informationen in Schichten.

Grundlagen

P

Parameters

Die "Einstellungen" eines KI-Modells. GPT-4 hat ca. 1,8 Billionen Parameter – Verbindungen zwischen Neuronen, die das Wissen speichern.

Technik

Prompt

Die Eingabe oder Anweisung, die Sie der KI geben. Ein guter Prompt ist präzise, kontextreich und strukturiert.

Prompting

Prompt Engineering

Die Kunst, effektive Prompts zu schreiben. Das Kernthema dieser Academy – systematisch bessere Ergebnisse erzielen.

Prompting

Q

Query

Die Anfrage oder Sucheingabe. In Suchmaschinen und KI-Systemen: das, wonach Sie suchen oder fragen.

Grundlagen

R

RAG

Retrieval-Augmented Generation – KI greift auf externe Datenquellen zu, um aktuelle und genaue Antworten zu geben.

Technik

Reasoning

Schlussfolgern oder logisches Denken. Moderne KI kann komplexe Probleme Schritt für Schritt lösen (Chain of Thought).

Grundlagen

RLHF

Reinforcement Learning from Human Feedback – Training durch menschliches Feedback. ChatGPT wurde so verbessert.

Technik

S

Stable Diffusion

Ein Open-Source-Bildgenerator. Kann lokal auf eigenen Rechnern laufen, keine Cloud nötig.

Bild-KI

System Prompt

Die Hintergrundanweisung, die das Verhalten der KI definiert. Wie die "Rolle", die die KI übernimmt.

Prompting

T

Temperature

Steuert die Kreativität der KI. Niedrig (0.0) = vorhersehbar, faktisch. Hoch (1.0+) = kreativ, überraschend.

Technik

Token

Die kleinste Einheit, die KI verarbeitet. Ein Token ist etwa 3/4 eines Wortes. GPT-4 verarbeitet bis zu 8.000 Tokens.

Technik

Transformer

Die Architektur hinter modernen Sprachmodellen. Ermöglicht es, Beziehungen zwischen Wörtern über große Distanzen zu erkennen.

Grundlagen

U

Use Case

Ein konkreter Anwendungsfall. Wie nutzt man KI im Alltag? Texte schreiben, Code debuggen, Ideen sammeln...

Anwendung

V

Vector Database

Eine Datenbank für Embeddings. Speichert Bedeutungen als mathematische Vektoren für schnelle Ähnlichkeitssuche.

Technik

W

Wahrscheinlichkeit

KI wählt das nächste Wort basierend auf Wahrscheinlichkeiten. Nicht auf "Wissen", sondern auf statistischen Mustern.

Grundlagen

Weights

Die Gewichtungen in einem neuronalen Netz. Bestimmen, wie stark verschiedene Verbindungen das Ergebnis beeinflussen.

Technik

Z

Zero-Shot

KI löst eine Aufgabe ohne Beispiele – rein aus der Anweisung. Zeigt die Generalisierungsfähigkeit moderner Modelle.

Prompting

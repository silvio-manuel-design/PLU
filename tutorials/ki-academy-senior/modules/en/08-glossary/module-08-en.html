The AI Glossary

All the terms you need to know – explained in plain English

50+ Terms
A-Z Sorted
∞ Useful
Browse the glossary
A B C D E F G H I K L M N P Q R S T U V W Z

A

Algorithm

A fixed set of rules or instructions for solving a problem. Like a recipe: step by step, the algorithm leads to a result.

Basics

API

Application Programming Interface – the "language" that different programs use to communicate with each other. Like a translator between two software systems.

Technical

Assistant

An AI system that performs tasks or answers questions. ChatGPT, Claude, or Google Assistant are examples of AI assistants.

Application

B

Bias

Prejudice or distortion. AI systems can adopt biases from their training data – for example, stereotypical gender roles.

Ethics

Bot

An automated computer program that carries out tasks without human intervention. Chatbots conduct text-based conversations.

Application

C

Chain of Thought

A technique where the AI thinks step by step and explains its reasoning. Leads to better results on complex tasks.

Prompting

Chatbot

A computer program that conducts text-based conversations. Modern chatbots like ChatGPT use large language models for natural dialogue.

Application

Context Window

The "memory" of the AI – how much text it can process at once. GPT-4 can handle approx. 25,000 words, Claude up to 100,000.

Technical

D

Deep Learning

An advanced form of machine learning using artificial neural networks. The foundation of modern AI systems like GPT.

Basics

DALL-E

An AI system by OpenAI that creates images from text descriptions. The "A" stands for Salvador Dalí, "E" for WALL-E.

Image AI

E

Embedding

The conversion of text into mathematical vectors so that the AI can understand and compare meanings.

Technical

F

Few-Shot Learning

The ability of an AI to learn from a few examples. In prompting: showing several examples of what the output should look like.

Prompting

Fine-Tuning

Retraining an AI model for specific tasks. Makes the model better in a particular area.

Technical

G

Generative AI

AI that creates new content: texts, images, music, code. In contrast to analytical AI, which only evaluates data.

Basics

GPT

Generative Pre-trained Transformer – the technology behind ChatGPT. A large language model that can predict and generate text.

Basics

Guardrails

Safety mechanisms that prevent AI from generating harmful or inappropriate content. Like seatbelts for AI responses.

Safety

H

Hallucination

When AI invents false information but presents it confidently. One of the biggest challenges with LLMs.

Critical Thinking

I

Inference

Applying a trained AI model to new data. When you chat with ChatGPT, inference is running.

Technical

K

AI

Artificial Intelligence – computer programs that perform tasks normally requiring human intelligence: learning, problem-solving, language understanding.

Basics

L

LLM

Large Language Model – a large language model trained on vast amounts of text. GPT-4, Claude, and Gemini are LLMs.

Basics

M

Machine Learning

Machine Learning (ML) – computers learn from data without being explicitly programmed. The foundation of modern AI.

Basics

Midjourney

A popular AI tool for image generation. Known for particularly aesthetic and artistic results.

Image AI

Multimodal

AI that can process different data types: text, images, audio, video. GPT-4V can "see" images and describe them.

Technical

N

Neural Network

A computer model inspired by the human brain. Millions of artificial "neurons" process information in layers.

Basics

P

Parameters

The "settings" of an AI model. GPT-4 has approx. 1.8 trillion parameters – connections between neurons that store knowledge.

Technical

Prompt

The input or instruction you give to the AI. A good prompt is precise, rich in context, and well structured.

Prompting

Prompt Engineering

The art of writing effective prompts. The core topic of this Academy – systematically achieving better results.

Prompting

Q

Query

The request or search input. In search engines and AI systems: what you are searching for or asking about.

Basics

R

RAG

Retrieval-Augmented Generation – AI accesses external data sources to provide current and accurate answers.

Technical

Reasoning

Drawing conclusions or logical thinking. Modern AI can solve complex problems step by step (Chain of Thought).

Basics

RLHF

Reinforcement Learning from Human Feedback – training through human feedback. How ChatGPT was improved.

Technical

S

Stable Diffusion

An open-source image generator. Can run locally on your own computer, no cloud required.

Image AI

System Prompt

The background instruction that defines the AI's behavior. Like the "role" the AI takes on.

Prompting

T

Temperature

Controls the creativity of the AI. Low (0.0) = predictable, factual. High (1.0+) = creative, surprising.

Technical

Token

The smallest unit the AI processes. A token is about 3/4 of a word. GPT-4 processes up to 8,000 tokens.

Technical

Transformer

The architecture behind modern language models. Enables recognizing relationships between words over large distances.

Basics

U

Use Case

A concrete application scenario. How do you use AI in everyday life? Writing texts, debugging code, brainstorming ideas...

Application

V

Vector Database

A database for embeddings. Stores meanings as mathematical vectors for fast similarity search.

Technical

W

Probability

AI chooses the next word based on probabilities. Not on "knowledge", but on statistical patterns.

Basics

Weights

The weightings in a neural network. Determine how strongly different connections influence the result.

Technical

Z

Zero-Shot

AI solves a task without examples – purely from the instruction. Shows the generalization ability of modern models.

Prompting

📤 Audacity Export: MP3, WAV, OGG

Exportiere deine Audio-Projekte in verschiedene Formate

Über den Export

Der Export ist der letzte Schritt in der Audio-Bearbeitung mit Audacity. Dabei wird das Projekt in ein standardisiertes Audioformat umgewandelt, das auf verschiedenen Geräten und Plattformen abgespielt werden kann.

💡 Wichtig: Audacity speichert Projekte in einem speziellen Format (.aup3). Zum Teilen oder Veröffentlichen musst du das Projekt als Audiodatei exportieren.

Unterschied zwischen Projekt und Export

Audacity Projekt (.aup3)

  • Enthält alle Spuren, Effekte und Bearbeitungen
  • Kann nur in Audacity geöffnet werden
  • Erlaubt weitere Bearbeitungen
  • Kleinere Dateigröße als exportierte Dateien

Exportierte Audiodatei

  • Endgültige Version des Audiomaterials
  • Kann auf verschiedenen Geräten abgespielt werden
  • Keine Bearbeitungsmöglichkeit (ohne Projektdatei)
  • Unterschiedliche Formate mit verschiedenen Eigenschaften

Exportvorgang

Schritt 1: Projekt vorbereiten

  • Stelle sicher, dass alle gewünschten Effekte angewendet wurden
  • Überprüfe die Lautstärkepegel (kein Clipping)
  • Stelle sicher, dass keine unerwünschten Stellen vorhanden sind
  • Speichere das Projekt (Datei > Speichern unter...)

Schritt 2: Export starten

  1. Gehe zu Datei > Export > Export als...
  2. Wähle das gewünschte Format aus der Liste
  3. Gib einen Dateinamen ein
  4. Wähle den Speicherort
  5. Klicke auf "Speichern"

MP3-Export

Eigenschaften

  • Verlustbehaftetes Kompressionsformat
  • Kleine Dateigröße
  • Gute Kompatibilität mit Geräten und Software
  • Standardformat für Musik-Streaming

Export-Einstellungen

  1. Wähle Datei > Export > Export als MP3
  2. Wähle den Speicherort und Dateinamen
  3. Im folgenden Dialogfenster:
    • Bitrate: 128 kbps (Sprache), 192-320 kbps (Musik)
    • Encoder: LAME MP3 Encoder (muss installiert sein)
    • Titel, Künstler, Album: Optional Metadaten eingeben
  4. Klicke auf "Speichern"

Bitrate-Empfehlungen

  • 32 kbps: Sprache mit sehr geringer Bandbreite
  • 64 kbps: Sprache mit akzeptabler Qualität
  • 128 kbps: Gute Qualität für Sprache, ausreichend für Musik
  • 192 kbps: Hohe Qualität für Musik
  • 256 kbps: Sehr hohe Qualität
  • 320 kbps: Maximale Qualität (nahe verlustfrei)

WAV-Export

Eigenschaften

  • Unkomprimiertes Format (verlustfrei)
  • Sehr große Dateigröße
  • Höchste Qualität
  • Ideal für weitere Bearbeitung

Export-Einstellungen

  1. Wähle Datei > Export > Export als WAV
  2. Wähle den Speicherort und Dateinamen
  3. Im folgenden Dialogfenster:
    • WAV Typ: Microsoft 16 bit PCM (Standard)
    • Sample Rate: Behalte Originalrate oder wähle 44100 Hz für CD-Qualität
    • Kanäle: Mono oder Stereo je nach Bedarf
  4. Klicke auf "Speichern"

WAV-Verwendung

  • Archivierung von Originalmaterial
  • Weiterverarbeitung in anderer Software
  • Professionelle Anwendungen
  • CD-Brennen

OGG-Export

Eigenschaften

  • Verlustbehaftetes, aber hocheffizientes Kompressionsformat
  • Kleine Dateigröße bei guter Qualität
  • Offenes, patentfreies Format
  • Gute Alternative zu MP3

Export-Einstellungen

  1. Wähle Datei > Export > Export als OGG
  2. Wähle den Speicherort und Dateinamen
  3. Im folgenden Dialogfenster:
    • Qualitätsfaktor: 0.1-1.0 (0.5-0.7 für gute Qualität)
    • Bitrate: Variable oder konstante Bitrate
    • Metadaten: Optional Titel, Künstler, etc. eingeben
  4. Klicke auf "Speichern"

OGG-Verwendung

  • Web-Anwendungen (offenes Format)
  • Open-Source-Projekte
  • Hohe Qualität bei kleiner Datei
  • Alternative zu MP3

Andere Exportformate

FLAC (Free Lossless Audio Codec)

  • Verlustfreie Kompression
  • Kleinere Datei als WAV, gleiche Qualität
  • Gut für Archivierung

Speichern als Datei

  • Exportiert als unkomprimiertes Format
  • Ähnlich WAV, aber ohne Metadaten
  • Nur für spezielle Anwendungsfälle

LAME MP3 Encoder

Um MP3-Dateien zu exportieren, benötigst du den LAME MP3 Encoder. Falls dieser nicht installiert ist, zeigt Audacity eine entsprechende Meldung an.

Installation des LAME Encoders

  1. Lade den LAME Encoder von der Audacity-Website herunter
  2. Führe die Installation aus
  3. Starte Audacity neu
  4. Der MP3-Export sollte nun funktionieren
⚠️ Hinweis: Der LAME Encoder ist erforderlich für MP3-Export. Ohne diesen kann Audacity keine MP3-Dateien erstellen.

Qualitätsbewertung

Wie bewertest du die Exportqualität?

  • Höre die exportierte Datei auf verschiedenen Geräten an
  • Vergleiche mit dem Original im Projekt
  • Achte auf Verlust von Feinheiten oder Einführung von Artefakten
  • Überprüfe die Dateigröße im Verhältnis zur Qualität

Wann welche Qualität wählen?

  • Hohe Qualität (320 kbps MP3, 16-bit WAV): Für Veröffentlichung, Archivierung
  • Mittlere Qualität (192 kbps MP3): Für Web-Veröffentlichung, gute Balance
  • Niedrige Qualität (128 kbps MP3): Für Sprache, Vorschau, Bandbreitenbeschränkung

Praktische Übung

Führe folgende Schritte durch, um den Export zu üben:

  1. Öffne ein Audacity-Projekt oder erstelle ein neues
  2. Füge etwas Audiomaterial hinzu (Aufnahme oder Import)
  3. Wende einige Effekte an (z.B. Amplify, Fade In/Out)
  4. Exportiere das Projekt als MP3 mit 192 kbps
  5. Exportiere das gleiche Projekt als WAV
  6. Vergleiche Dateigröße und Qualität der beiden Dateien
  7. Exportiere das Projekt als OGG mit mittlerer Qualität

Best Practices für den Export

  • Speichere immer zuerst das Projekt (.aup3)
  • Exportiere in mehrere Formate für verschiedene Anwendungen
  • Überprüfe die exportierten Dateien auf Qualität
  • Verwende aussagekräftige Dateinamen
  • Behalte Originalprojekte für spätere Änderungen

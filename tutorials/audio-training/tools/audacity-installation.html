🔧 Audacity Installation & Setup

Installiere und richte Audacity für deine Audio-Produktion ein

Über Audacity

Audacity ist eine kostenlose, quelloffene Audio-Editing-Software, die auf Windows, macOS und Linux läuft. Sie eignet sich hervorragend für Aufnahme, Bearbeitung und Export von Audiodateien.

💡 Vorteile: Kostenlos, plattformübergreifend, umfangreiche Funktionen, aktive Community und kontinuierliche Weiterentwicklung.

Systemvoraussetzungen

  • Windows: Windows 7 oder neuer
  • macOS: macOS 10.13 oder neuer
  • Linux: Ubuntu 18.04 oder vergleichbare Distribution
  • RAM: Mindestens 1 GB (empfohlen: 4 GB oder mehr)
  • Festplattenspeicher: Ca. 100 MB für die Installation

Installation

Schritt 1: Download von der offiziellen Website

  1. Öffne deinen Webbrowser
  2. Gehe zu https://www.audacityteam.org/
  3. Klicke auf "Download" und wähle die Version für dein Betriebssystem
  4. Speichere die Installationsdatei auf deinem Computer

Schritt 2: Installation durchführen

Windows:

  1. Führe die heruntergeladene .exe-Datei aus
  2. Folge dem Installationsassistenten
  3. Wähle die gewünschten Optionen (Standardoptionen sind in der Regel gut)
  4. Warte auf die Installation
  5. Starte Audacity nach der Installation

macOS:

  1. Öffne die heruntergeladene .dmg-Datei
  2. Ziehe Audacity in den Programmordner
  3. Starte Audacity aus dem Programmordner

Linux (Ubuntu/Debian):

  1. Öffne ein Terminal
  2. Führe aus: sudo apt update
  3. Führe aus: sudo apt install audacity
  4. Starte Audacity über das Startmenü oder mit dem Befehl audacity

Erstkonfiguration

Sprache einstellen

  1. Öffne Audacity
  2. Gehe zu Edit > Preferences (oder Audacity > Preferences auf macOS)
  3. Wähle Language im linken Menü
  4. Wähle Deutsch (oder deine bevorzugte Sprache) aus der Liste
  5. Klicke auf OK und starte Audacity neu

Audiogerät konfigurieren

  1. Gehe zu Edit > Preferences > Devices
  2. Stelle sicher, dass deine Audiokarte als Host-API korrekt ausgewählt ist
  3. Wähle dein gewünschtes Aufnahme- und Wiedergabegerät aus
  4. Teste die Einstellungen mit einem kurzen Test

Erste Schritte

  1. Erstelle eine neue Projektdatei mit Datei > Neu
  2. Stelle sicher, dass deine Aufnahmespur korrekt konfiguriert ist
  3. Teste die Aufnahme mit einem kurzen Sprachtest
  4. Übe das Abspielen und Stoppen
  5. Speichere dein Projekt mit Datei > Speichern unter...
⚠️ Hinweis: Audacity speichert Projekte in einem speziellen Format (.aup oder .aup3). Zum Teilen oder Veröffentlichen musst du das Projekt als Audiodatei exportieren.

Häufige Probleme und Lösungen

Kein Ton bei Wiedergabe

  • Überprüfe die Wiedergabeeinstellungen in den Geräteeinstellungen
  • Stelle sicher, dass die Lautstärke nicht auf 0 ist
  • Überprüfe, ob andere Programme den Audiogerätetreiber verwenden

Probleme bei der Aufnahme

  • Überprüfe die Aufnahmequelle in den Geräteeinstellungen
  • Stelle sicher, dass das Mikrofon korrekt angeschlossen ist
  • Überprüfe die Aufnahmelautstärke

Verzögerungen oder Knackser bei der Aufnahme

  • Erhöhe den Latenz-Puffer in den Geräteeinstellungen
  • Verwende ein dediziertes Audiointerface anstelle des internen Chipsatzes

Du hast Audacity erfolgreich installiert und eingerichtet!

🎵 Audio-Player Projekt - Präsentation

Vollständige Lösung mit Web Audio API für Lehrkräfte

Projektübersicht

Dieses Projekt demonstriert die Erstellung eines vollständigen Audio-Players mit Hilfe der Web Audio API. Der Player bietet grundlegende Funktionen wie Wiedergabe, Pause, Stopp, Lautstärkeregelung und Effektanwendung.

💡 Ziel: Demonstration der Anwendung aller bisher gelernten Konzepte in einem praktischen Projekt.

Lernziele

In diesem Projekt wirst du:

  • Integration der Web Audio API in eine vollständige Anwendung
  • Erstellung einer benutzerfreundlichen Audio-Player-Oberfläche
  • Anwendung von Effekten und Filtern in Echtzeit
  • Verständnis für Audio-Graph-Strukturen
  • Praktische Umsetzung von Audio-Steuerungsfunktionen

Technische Anforderungen

  • HTML5 für die Struktur
  • CSS3 für das Styling
  • JavaScript mit Web Audio API für die Audio-Verarbeitung
  • Responsive Design für verschiedene Bildschirmgrößen
  • Barrierefreiheit für alle Benutzer

Projektstruktur

audio-player/

├── css/

Hauptkomponenten

1. Audio-Kontext

Der AudioContext ist das Herzstück des Players: 

const audioCtx = new (window.AudioContext || window.webkitAudioContext)();

2. Audio-Quellen

Verwaltung verschiedener Audio-Quellen (Dateien, Streams, Oszillatoren): 

const source = audioCtx.createBufferSource();
source.buffer = audioBuffer;

3. Effekt-Chain

Verbindung verschiedener Effekte für Audio-Manipulation: 

const gainNode = audioCtx.createGain();
const filterNode = audioCtx.createBiquadFilter();
const delayNode = audioCtx.createDelay(1.0);

// Verbindungskette
source.connect(gainNode);
gainNode.connect(filterNode);
filterNode.connect(delayNode);
delayNode.connect(audioCtx.destination);

Was ist Audio-Programmierung?

Audio-Programmierung bezieht sich auf die Erstellung und Verarbeitung von Audiodaten mit Hilfe von Programmiersprachen. Im Web-Umfeld nutzen wir dafür hauptsächlich JavaScript mit der Web Audio API.

Erweiterungsmöglichkeiten

1. Visualisierung

Mit der AnalyserNode können Frequenz- und Zeitdaten extrahiert werden: 

const analyser = audioCtx.createAnalyser();
analyser.fftSize = 2048;
source.connect(analyser);
analyser.connect(destination);

// Abfrage der Frequenzdaten
const bufferLength = analyser.frequencyBinCount;
const dataArray = new Uint8Array(bufferLength);
analyser.getByteFrequencyData(dataArray);

2. Equalizer

Implementierung eines parametrischen Equalizers mit mehreren BiquadFilterNodes: 

const bands = [80, 200, 500, 1000, 2000, 5000, 10000];
const filters = [];

for (let i = 0; i < bands.length; i++) {
  const filter = audioCtx.createBiquadFilter();
  filter.type = 'peaking';
  filter.frequency.value = bands[i];
  filter.Q.value = 1.0;
  filter.gain.value = 0;  // 0dB = keine Verstärkung
  
  filters.push(filter);
}

3. Playlist-Funktionalität

Implementierung einer Wiedergabeliste mit mehreren Tracks: 

class Playlist {
  constructor(player) {
    this.player = player;
    this.tracks = [];
    this.currentTrackIndex = 0;
  }
  
  addTrack(track) {
    this.tracks.push(track);
  }
  
  nextTrack() {
    if (this.currentTrackIndex < this.tracks.length - 1) {
      this.currentTrackIndex++;
      this.playCurrentTrack();
    }
  }
  
  previousTrack() {
    if (this.currentTrackIndex > 0) {
      this.currentTrackIndex--;
      this.playCurrentTrack();
    }
  }
}

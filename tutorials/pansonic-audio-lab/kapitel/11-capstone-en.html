Completion Checklist

Before you consider your project finished, go through this list:

Clear Concept I know exactly what I want to create
All Tracks Named Every track has a meaningful name
No Clicks or Pops All cuts are clean, fade-ins/outs present
EQ Adjusted Every track has basic EQ
Dynamics Controlled Compression where needed, balanced loudness
No Clipping Master level never reaches 0 dB
Export Tested The exported file has been played back
Published The project is online or has been shared

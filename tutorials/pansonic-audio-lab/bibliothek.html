    🧪 Mit Audacity selbst generieren

    Erstelle professionelle Testdateien direkt in Audacity:

    🥁 Metronom 120 BPM

    1. Generate → Click Track
    2. Tempo: 120 BPM
    3. Beats per measure: 4
    4. Duration: 60s
    5. File → Export → WAV

    📊 Frequenz-Sweep 20Hz – 20kHz

    1. Generate → Chirp
    2. Start: 20 Hz
    3. End: 20000 Hz
    4. Interpolation: Logarithmic
    5. Duration: 60s → Export

    🎵 Sine Testtöne

    1. Generate → Tone
    2. Waveform: Sine
    3. Frequenzen: 20, 100, 1000, 10000, 20000 Hz
    4. Amplitude: 0.8
    5. Duration: 10s → Export

    🔇 Rauschunterdrückung Demo

    1. BBC Sound Effects → "noise" laden
    2. Effekt → Noise Removal
    3. Get Noise Profile (Rauschen markieren)
    4. Gesamten Track markieren
    5. Noise Removal anwenden → Export

    Prompting-Guide

    1

    Struktur ist King

    Teile deinen Prompt in Abschnitte: Genre → BPM → Instrumentation → Mood → Production

    2

    Spezifisch statt vage

    "85 BPM dusty vinyl" statt nur "lo-fi". Je präziser, desto besser das Ergebnis.

    3

    Settings verstehen

    Stability = Konsistenz vs. Kreativität. Similarity = Wie nah am Original.

    4

    Iterieren

    Erster Prompt nicht perfekt? Anpassen, verfeinern, wiederholen. Das ist der Prozess.

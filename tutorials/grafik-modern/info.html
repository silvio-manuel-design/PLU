Intel & Mission Briefing

Alles, was du über Grafik Quest wissen musst

🎯 Mission Objectives

Grafik Quest ist ein gamifiziertes Lern-Erlebnis für angehende Digital Creators. Entwickelt an der HTBLA Traun im Fach Medientechnik.

🎮 Ziele:

  • Pixel- vs. Vektorgrafiken verstehen und anwenden
  • GIMP & Inkscape als professionelle Tools beherrschen
  • KI als Sparring-Partner nutzen (nicht ersetzen!)
  • Eigenes Logo-Design-Projekt umsetzen

⚡ System Specs

🛠️ Tools

  • GIMP 2.10+ - Pixel-Editor
  • Inkscape 1.3+ - Vektor-Editor
  • VS Code - Code-Editor (optional)

💻 System

  • Windows 10/11, macOS oder Linux
  • 4GB RAM minimum
  • Modern Browser (Chrome, Firefox, Edge)

📡 Online

  • Internet für Downloads
  • KI-Tools (ChatGPT, Claude)
  • W3Schools Referenz

🧠 KI Protocol

Unser Mindset

KI ist dein Sparring-Partner, nicht dein Ersatz-Gehirn. Wir nutzen KI zum Lernen, nicht zum Abschreiben.

❌ VERBOTEN

  • KI-Bildgeneratoren (DALL-E, Midjourney)
  • Copy-Paste ohne Verständnis
  • "Mach mir ein Logo"-Prompts

✅ ERLAUBT

  • Erklärungs-Prompts
  • Planungs-Hilfe
  • Fehler-Analyse

🎯 Inkscape – Logo-Design

Dein erstes professionelles Vektor-Logo

📌 1. Projektziel

Erstelle ein eigenes Logo für eines der folgenden Themen:

  • Dein persönliches Portfolio
  • Ein fiktives Start-up (z. B. „GreenCycle – Recycling-App“)
  • Ein Schulclub oder Projektgruppe

Das Logo soll:

  • Skalierbar sein (klar bei jeder Größe)
  • Eine klare Botschaft vermitteln
  • Als .svg fürs Web nutzbar sein

📁 2. Vorbereitung

  1. Überlege dir: Was soll dein Logo ausdrücken? (z. B. Nachhaltigkeit, Technik, Kreativität)
  2. Skizziere grobe Ideen auf Papier
  3. Starte Inkscape
  4. Gehe zu Datei → Neu, falls keine neue Datei geöffnet ist

✏️ 3. Schritt-für-Schritt-Anleitung

3.1 Text hinzufügen

  1. Klicke auf das Text-Werkzeug (T in der Werkzeugleiste)
  2. Klicke auf die Zeichenfläche und gib deinen Logonamen ein (z. B. „GreenCycle“)
  3. Wähle im rechten Eigenschaften-Fenster eine passende Schriftart (z. B. „Arial Bold“)
  4. Stelle die Größe auf ca. 48 pt ein

3.2 Text in Pfad umwandeln

  1. Wähle den Text mit dem Auswahl-Werkzeug (Pfeil) an
  2. Gehe zu Pfad → Objekt in Pfad umwandeln
  3. Oder drücke die Tastenkombination: Umschalt+Strg+C
  4. Der Text zeigt nun blaue Knotenpunkte – er ist jetzt ein Pfad!
⚠️ Achtung: Danach kannst du den Textinhalt nicht mehr ändern!
→ Stelle sicher, dass der Text korrekt ist, bevor du umwandelst.

3.3 Logo gestalten

Jetzt kannst du kreativ werden:

  • Wähle das Pfad bearbeiten-Werkzeug (Knotensymbol)
  • Ziehe an Knotenpunkten, um Buchstaben zu verformen
  • Füge mit dem Rechteck- oder Ellipsen-Werkzeug Symbole hinzu
  • Ändere Farben über die untere Farbleiste oder das rechte Eigenschaften-Fenster

💡 Tipp: Halte das Logo einfach – je weniger Details, desto besser erkennbar!

3.4 Exportieren

  1. Gehe zu Datei → Speichern unter
  2. Wähle als Format „Plain SVG“
  3. Gib einen Namen ein (z. B. mein-logo.svg)
  4. Klicke auf Speichern
  5. (Optional) Für Präsentationen: Datei → Exportieren als… → PNG

✅ 4. Prüfliste – Hast du alles gemacht?

  • ☐ Der Logotext wurde vor der Umwandlung geprüft
  • ☐ Text wurde in Pfad umgewandelt (Umschalt+Strg+C)
  • ☐ Logo enthält mindestens Text + ein einfaches Symbol
  • ☐ Logo wurde als .svg gespeichert
  • ☐ Eine .svg-Datei wurde zur Abgabe vorbereitet
  • ☐ Das Logo wirkt klar und erkennbar (auch in klein)

🧠 5. KI-Prompt-Training (optional)

Aufgabe: Formuliere einen Prompt, mit dem du KI bitten würdest, dir bei der Ideenfindung für ein Logo zu helfen – ohne dass sie dir ein fertiges Design vorgibt.

💡 Beispiel:
„Gib mir 3 Fragen, die ich mir stellen sollte, bevor ich ein Logo für ein Nachhaltigkeits-Start-up entwerfe.“

🎓 Herzlichen Glückwunsch! Du hast dein erstes Vektor-Logo erstellt.

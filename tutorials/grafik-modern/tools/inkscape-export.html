📤 Inkscape – Export - SVG & PNG

So bereitest du Vektorgrafiken perfekt für Web und Präsentation vor

⚠️ 1. Speichern ≠ Exportieren!

Inkscape speichert standardmäßig im Format .svg – das ist gut! Aber: Wenn du ein Bild für PowerPoint, Moodle oder eine Webseite brauchst, musst du es oft als PNG exportieren.

⚠️ Achtung: „Speichern unter“ ändert nur den Dateinamen –
für andere Formate nutze immer „Exportieren als…“.

📊 2. Welches Format wofür?

Format Vorteile Nachteile Verwendung
SVG Skalierbar, klein, editierbar, webfreundlich Nicht alle Programme unterstützen es (z. B. ältere Word-Versionen) Webseiten, Logos, Icons, interaktive Grafiken
PNG Überall lesbar, unterstützt Transparenz Nicht skalierbar – wird bei Zoom unscharf Präsentationen, Moodle, soziale Medien, Druckvorlagen

🛠️ 3. So exportierst du richtig

3.1 Als SVG (fürs Web)

  1. Gehe zu Datei → Speichern unter
  2. Wähle den Speicherort
  3. Stelle sicher, dass das Format „Plain SVG“ ausgewählt ist
  4. Klicke auf Speichern

🔗 → Warum SVG ideal für Webseiten ist

3.2 Als PNG (für Präsentationen)

  1. Gehe zu Datei → Exportieren als…
  2. Wähle PNG als Format
  3. Stelle die Auflösung ein (z. B. 150–300 dpi für Druck)
  4. Klicke auf Exportieren
  5. Wähle Speicherort und Dateinamen

🌐 4. Einbindung im Web

Nach dem Export kannst du dein Logo in HTML einbinden: 

<!-- Direkt als SVG (empfohlen) -->
<img src="logo.svg" alt="Mein Logo">

<!-- Oder eingebettet (für Animationen) -->
<svg width="200" height="50">
  <use href="logo.svg#symbol"></use>
</svg>

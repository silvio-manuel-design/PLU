🔧 GIMP – Installation & Setup

So richtest du das kostenlose Bildbearbeitungsprogramm ein

📥 1. GIMP herunterladen

GIMP ist kostenlos, Open Source und läuft auf Windows, macOS und Linux. Lade es von der offiziellen Website herunter:

→ GIMP herunterladen

Wähle dein Betriebssystem und folge den Installationsanweisungen.

⚙️ 2. Ersteinrichtung

Nach der Installation startet GIMP mit einer Standardkonfiguration. Du kannst optional folgende Einstellungen vornehmen:

  • Sprache: GIMP nutzt standardmäßig die Systemsprache.
    Möchtest du Englisch (für bessere Online-Hilfe), ändere die Systemsprache temporär oder nutze die englische Version.
  • Arbeitsbereich: Beim ersten Start werden drei Fenster geöffnet:
    • Hauptfenster
    • Werkzeugkasten
    • Ebenen-/Farben-Dock
💡 Tipp: Schließe niemals das Hauptfenster – sonst beendest du GIMP!
Die anderen Fenster kannst du frei verschieben oder andocken.

🖥️ 3. Teste die Installation

Öffne GIMP und erstelle ein neues Bild:

  1. Klicke auf Datei → Neu
  2. Wähle eine Größe (z.B. 800 × 600 Pixel)
  3. Klicke auf OK
  4. Zeichne etwas mit dem Pinsel-Werkzeug

Wenn alles funktioniert, bist du bereit für die nächsten Schritte!

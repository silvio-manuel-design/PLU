🔧 Inkscape – Installation & Setup

So richtest du das kostenlose Vektorgrafik-Programm ein

📥 1. Inkscape herunterladen

Inkscape ist kostenlos, Open Source und läuft auf Windows, macOS und Linux. Lade es von der offiziellen Website herunter:

→ Inkscape herunterladen

Wähle dein Betriebssystem und folge den Installationsanweisungen.

⚙️ 2. Ersteinrichtung & Spracheinstellung

Nach der Installation startet Inkscape mit einer Standardansicht. Falls die Sprache nicht automatisch auf Deutsch umgestellt wird, kannst du sie manuell ändern:

  1. Öffne Inkscape
  2. Gehe zu Bearbeiten → Voreinstellungen
  3. Im linken Menü wähle Interface → Language
  4. Wähle Deutsch (German) aus der Liste
  5. Klicke auf OK
  6. Starte Inkscape neu – die Änderung wird erst nach dem Neustart wirksam!
💡 Hinweis: Die Tutorials im Hilfe-Menü („Hilfe → Tutorials") sind in der eingestellten Sprache verfügbar.
Dort findest du auch offizielle Anleitungen zu Pfaden, Texten und Formen.

🖥️ 3. Teste die Installation

Erstelle ein einfaches Vektorobjekt:

  1. Klicke auf das Rechteck-Werkzeug (links in der Werkzeugleiste)
  2. Ziehe auf der Zeichenfläche ein Rechteck auf
  3. Klicke auf das Auswahl-Werkzeug (Pfeil-Symbol)
  4. Ziehe an den Ecken – das Rechteck bleibt scharf, egal wie groß du es machst!

Wenn alles funktioniert, bist du bereit für die nächsten Schritte!

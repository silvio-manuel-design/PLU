## 🎨 Leonardo AI Settings (für alle Prompts)

### Empfohlene Konfiguration:

| Setting | Wert | Begründung |
|---------|------|------------|
| **Model** | Leonardo Diffusion XL | Beste Photorealistik |
| **Style** | Cinematic | Filmähnliche Qualität |
| **Guidance Scale** | 7-8 | Balance Kreativität/Kontrolle |
| **Steps** | 30-40 | Optimal für Details |
| **Resolution** | 2752 x 1536 | Passt zu aktuellen Bildern |
| **Negative Prompt** | cartoon, illustration, ugly, deformed, blurry, low quality | Vermeidet Artefakte |

### Color Palette Guidelines:
```
Primary: Deep navy (#0a1628), Warm beige (#f5f1eb)
Accent: Cyan (#39d0d8), Soft blue (#58a6ff)
Avoid: Neon-pink, saturated orange, pure black
```

## ⚡ Schnell-Generierungs-Tipps

1. **PhotoReal aktivieren** für authentische Menschen
2. **Alchemy** für bessere Details
3. **Prompt Magic** (strength: 0.4-0.5) für feinere Kontrolle
4. **4-6 Variationen** generieren, beste auswählen
5. **Upscale** (2x) für finale Version

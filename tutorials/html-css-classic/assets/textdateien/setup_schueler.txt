## 🛠️ **Setup für Schüler:innen**

1. **Lade das gesamte Verzeichnis** herunter (z. B. über Schulserver)
2. **Öffne den Ordner in VS Code** (nie nur eine Datei!)
3. **Installiere „Live Server“** (Erweiterung)
4. **Klicke rechts unten auf „Go Live“** – fertig!

> ⚠️ **Warnung**: Ohne **Live Server** funktionieren externe CSS/JS/Pfade **nicht**!

02 – Seitenstruktur | Musterlösung 🏗️

Für Lehrkräfte – nicht für Schüler sichtbar

🔍 Aufgabe 1 – Analyse (Musterantwort)

Fehlende Elemente & Konsequenzen:

  1. <!DOCTYPE html> fehlt: Browser nutzt „Quirks Mode“ → unvorhersehbares Layout.
  2. charset fehlt: Umlaute werden falsch dargestellt (z. B. „Österreich“ → „Ã–sterreich“).
  3. Viewport-Meta-Tag fehlt: Seite wird auf allen Geräten wie auf Desktop gerendert → horizontales Scrollen, winzige Schrift.
  4. lang="de" fehlt: Screenreader nutzen falsche Sprache; Suchmaschinen verstehen den Inhalt schlechter.

🧱 Aufgabe 2 – Musterlösung: heimat.html

<!DOCTYPE html>
<html lang="de">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Traun – Meine Heimatstadt</title>
</head>
<body>
  <h1>Traun</h1>
  <p>
    Traun ist eine Stadt im Bezirk Linz-Land in Oberösterreich.
    Bekannt ist sie für ihre historische Altstadt und den Trauner See.
  </p>
</body>
</html>

💡 Hinweise für das Fachgespräch

  • Kann der Schüler erklären, warum jedes der 7 Pflichtelemente nötig ist?
  • Weiß er, was passiert, wenn charset fehlt?
  • Versteht er, dass lang="de" für Barrierefreiheit und SEO wichtig ist?
  • Kann er seine Lösung ohne Code-Datei erklären?

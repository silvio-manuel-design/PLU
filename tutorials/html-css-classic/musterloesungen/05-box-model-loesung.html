05 – Box-Modell | Musterlösung 📦

Für Lehrkräfte – nicht für Schüler sichtbar

🔍 Aufgabe 1 – Analyse (Musterantwort)

  1. Gesamtbreite: 200px (Inhalt) + 2×20px (Padding) + 2×5px (Border) = 250px.
  2. Problem: Bei zwei Boxen à 200px nebeneinander würde der Container mindestens 500px breit sein – zu viel für viele Layouts.
  3. box-sizing: border-box: Die angegebene Breite (width) bezieht sich auf die gesamte Box – inkl. Padding und Border.
  4. Universelle Regel: Mit * { box-sizing: border-box; } gilt das für alle Elemente – Layouts werden stabil und vorhersehbar.

🧱 Aufgabe 2 – Musterlösung

Datei: boxen.html

<!DOCTYPE html>
<html lang="de">
<head>
  <meta charset="UTF-8">
  <title>Box-Modell Test</title>
  <link rel="stylesheet" href="css/boxen.css">
</head>
<body>
  <div class="box">Box 1</div>
  <div class="box">Box 2</div>
</body>
</html>

Datei: css/boxen.css

* {
  box-sizing: border-box;
}

.box {
  width: 300px;
  padding: 20px;
  border: 3px solid #e67e22;
  margin: 15px;
  background-color: #fdf7f0;
}

💡 Hinweise für das Fachgespräch

  • Kann der Schüler die vier Schichten benennen (Content, Padding, Border, Margin)?
  • Versteht er, warum margin nicht in border-box enthalten ist?
  • Weiß er, dass die Regel mit * die Layout-Berechnung vereinfacht?
  • Kann er seine Lösung im Entwickler-Tools erklären – oder nur zeigen?

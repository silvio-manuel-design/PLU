04 – Farben & Vererbung | Musterlösung 🎨

Für Lehrkräfte – nicht für Schüler sichtbar

🔍 Aufgabe 1 – Analyse (Musterantwort)

  1. Farbe von <h1>: Rot (#FF0000), weil color: inherit die Schriftfarbe vom <body> erbt.
  2. Schriftgröße von <p>: 16px × 1.5 = 24px.
  3. 1rem statt 16px: rem respektiert die Nutzer-Einstellung im Browser – px nicht.
  4. Browser-Zoom: Bei px bleibt die Schrift fest – blinde oder sehbehinderte Nutzer können sie nicht vergrößern. Bei rem/ em funktioniert das.

🎨 Aufgabe 2 – Musterlösung

Datei: farbtest.html

<!DOCTYPE html>
<html lang="de">
<head>
  <meta charset="UTF-8">
  <title>Farbtest</title>
  <link rel="stylesheet" href="css/farben.css">
</head>
<body>
  <h1>Meine Überschrift</h1>
  <p>Dieser Absatz hat eine eigene Farbe und Größe.</p>
</body>
</html>

Datei: css/farben.css

body {
  color: #2c3e50;
  font-size: 1rem;
}

h1 {
  color: inherit;
  font-size: 1.8rem;
}

p {
  color: rgb(230, 126, 34);
  font-size: 1.4em;
}

💡 Hinweise für das Fachgespräch

  • Versteht der Schüler, was „Vererbung“ in CSS bedeutet?
  • Kann er erklären, warum background-color nicht vererbt wird?
  • Weiß er, wie man HEX in RGB umrechnet (z. B. #FF0000 = rgb(255,0,0))?
  • Kann er seine Maßeinheiten begründen – oder hat er sie nur übernommen?

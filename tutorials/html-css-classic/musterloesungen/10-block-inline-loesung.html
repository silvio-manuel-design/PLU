10 – Block vs. Inline | Musterlösung 🧱↔️🔤

Für Lehrkräfte – nicht für Schüler sichtbar

🔍 Aufgabe 1 – Analyse (Musterantwort)

  1. Ungültig: Inline-Elemente (<span>) dürfen keine Block-Elemente (<div>) enthalten.
  2. Verletzte Regeln: (1) Block-Elemente starten eine neue Zeile, Inline-Elemente nicht → logischer Konflikt.
    (2) Die HTML-Spezifikation verbietet diese Verschachtelung – Validator meldet Fehler.
  3. Browser-Verhalten: Der Browser "korrigiert" stillschweigend: Er schließt das <span> vor dem <div> und öffnet es danach wieder → kaputte Struktur.
  4. Korrektur: Entweder <div><span>...</span></div> (Block außen) oder beides als Inline/Block vereinheitlichen.

🧱🔤 Aufgabe 2 – Musterlösung

Datei: layout-test.html

<h2>Block-Elemente</h2>
<div>Box 1</div>
<div>Box 2</div>
<div>Box 3</div>

<p>
  <span class="wort1">Wort1</span>
  <span class="wort2">Wort2</span>
  <span class="inlineblock">Wort3 (inline-block)</span>
</p>

Datei: css/display.css

div {
  background: #e8f4fc;
  padding: 12px;
  margin: 8px 0;
}

.wort1 { color: #e67e22; }
.wort2 { color: #27ae60; }
.inlineblock {
  display: inline-block;
  background: #fdf7f0;
  padding: 4px 8px;
  color: #2c3e50;
}

💡 Hinweise für das Fachgespräch

  • Kann der Schüler erklären, warum Block-Elemente die volle Breite beanspruchen?
  • Versteht er, dass Padding/Margin bei Inline-Elementen nur horizontal wirken?
  • Weiß er, dass inline-block Breite/Höhe erlaubt, aber im Textfluss bleibt?
  • Kann er seine Struktur ohne Code begründen – oder nur zeigen?

09 – Listen & Selektoren | Musterlösung 📋

Für Lehrkräfte – nicht für Schüler sichtbar

🔍 Aufgabe 1 – Analyse (Musterantwort)

  1. Semantik: Navigation = Liste von Links → muss mit <ul><li> umgesetzt werden. <div> hat keine Bedeutung für Screenreader.
  2. Design: Unterstriche bei horizontalen Navigationen wirken unruhig und unprofessionell.
  3. Korrekte Struktur: <nav><ul><li><a>...</a></li></ul></nav>.
  4. CSS: list-style: none; (keine Punkte), display: flex; (horizontal), text-decoration: none; (kein Unterstrich).

🧭 Aufgabe 2 – Musterlösung

Datei: liste.html

<nav>
  <ul>
    <li><a href="index.html">Start</a></li>
    <li><a href="kontakt.html">Kontakt</a></li>
  </ul>
</nav>

<ul>
  <li>Webentwicklung
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Grafik</li>
</ul>

Datei: css/stil.css

nav ul {
  list-style: none;
  padding: 0;
  margin: 0;
  display: flex;
  gap: 20px;
}

nav a {
  text-decoration: none;
  color: #2c3e50;
}

ul ul {
  list-style-type: circle;
}

💡 Hinweise für das Fachgespräch

  • Kann der Schüler erklären, warum <nav> + <ul> semantisch korrekt ist?
  • Versteht er den Unterschied zwischen list-style-type und list-style?
  • Weiß er, dass color vererbt wird, aber padding nicht?
  • Kann er seine Lösung ohne Datei erklären – oder nur zeigen?

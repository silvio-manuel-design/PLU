03 – CSS-Grundlagen | Musterlösung 🎨

Für Lehrkräfte – nicht für Schüler sichtbar

🔍 Aufgabe 1 – Analyse (Musterantwort)

Syntaxfehler:

  1. Gleichheitszeichen statt Doppelpunkt: color = red → muss color: red; sein.
  2. Fehlendes Semikolon und Einheit: font-size: 24 → muss font-size: 24px; oder 1.5rem; sein.
  3. Ungültige Farbe: #yellow ist kein gültiger HEX-Wert. Korrekt: yellow, #ffff00 oder rgb(255, 255, 0).

🎨 Aufgabe 2 – Musterlösung

Datei: mein-stil/index.html

<!DOCTYPE html>
<html lang="de">
<head>
  <meta charset="UTF-8">
  <title>Mein Stil</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <h1>Willkommen zu meinem Stil</h1>
  <p>Dieser Text hat einen Hintergrund und Abstand.</p>
  <a href="#">Ein Link ohne Unterstrich</a>
</body>
</html>

Datei: mein-stil/css/style.css

h1 {
  color: #e67e22;
  font-size: 1.8rem;
}

p {
  background-color: #fdf7f0;
  padding: 16px;
  line-height: 1.6;
}

a {
  text-decoration: none;
  color: rgb(230, 126, 34);
}

💡 Hinweise für das Fachgespräch

  • Kann der Schüler erklären, warum : und ; nötig sind?
  • Versteht er den Unterschied zwischen px, em, rem?
  • Weiß er, warum externe CSS-Dateien besser sind als <style>?
  • Kann er seine Farbwahl und Einheiten begründen?

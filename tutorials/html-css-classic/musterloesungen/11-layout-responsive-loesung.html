11 – Layout & Responsive | Musterlösung 📱↔️🖥️

Für Lehrkräfte – nicht für Schüler sichtbar

🔍 Aufgabe 1 – Analyse (Musterantwort)

  1. Anordnung: Vertikal (untereinander), weil flex-direction: column.
  2. flex: 1: Sagt: „Teile den verfügbaren Platz gleichmäßig auf.“ Ohne würde jede Box nur so breit sein wie ihr Inhalt (bei Column: so hoch wie Inhalt).
  3. Korrektur: flex-direction: row; (Standardwert, oft nicht nötig anzugeben).
  4. Responsive Vorteil: Flexbox passt sich automatisch an – keine festen Breiten, keine Floats, kein Clearfix.

🧱 Aufgabe 2 – Musterlösung

Datei: layout.html

<div class="container">
  <div class="box1">Box 1</div>
  <div class="box2">Box 2</div>
  <div class="box3">Box 3</div>
</div>

Datei: css/flex.css

.container {
  display: flex;
  gap: 16px;
}

.container > div {
  flex: 1;
  padding: 20px;
  background: #e8f4fc;
  text-align: center;
}

💡 Hinweise für das Fachgespräch

  • Kann der Schüler erklären, warum flex: 1 ein Kurzbefehl für flex-grow: 1 ist?
  • Versteht er, dass Flexbox nur eine Dimension (Hauptachse) kontrolliert?
  • Weiß er, dass Flexbox nicht für komplexes 2D-Layout (Grid) gedacht ist?
  • Kann er seine Lösung ohne Datei erklären – oder nur zeigen?

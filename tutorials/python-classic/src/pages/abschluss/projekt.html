Python Classic / Abschluss

Dein PyBuddy

Bringe alles Gelernte zusammen: Baue deinen interaktiven Python-Assistenten mit allen Features, die du in 13 Kapiteln gelernt hast.

90 Min Schwer

Lernziele

  • Du kombinierst Variablen, Strings, Bedingungen, Schleifen und Funktionen in einem Projekt
  • Du nutzt Listen und Dictionaries für echte Datenstrukturen
  • Du strukturierst deinen Code mit Funktionen und Modulen
  • Du baust ein interaktives CLI-Programm mit Menüführung

Projektbeschreibung

In diesem Abschlussprojekt baust du PyBuddy v1.0 — deinen interaktiven Python-Assistenten. Du hast in jedem Kapitel einen kleinen Baustein dazu beigetragen. Jetzt wird aus allen Bausteinen ein funktionierendes Programm.

Was PyBuddy können soll

  • Dich mit deinem Namen begrüßen (Kapitel 02)
  • Einfache Rechnungen durchführen (Kapitel 03)
  • Eine To-Do-Liste verwalten (Kapitel 06)
  • Dein Nutzerprofil speichern (Kapitel 07)
  • Eine Menüführung mit Schleifen (Kapitel 05)
  • Funktionen für Wiederverwendbarkeit (Kapitel 08)
  • Konfiguration in JSON speichern (Kapitel 10)

Projekt-Struktur

Organisiere deinen Code in mehrere Dateien:

Ordnerstruktur 
pybuddy/
├── main.py              # Einstiegspunkt & Menü
├── config.py            # Konfiguration laden/speichern
├── tasks.py             # To-Do-Liste Verwaltung
├── calculator.py        # Rechner-Funktionen
└── profile.py           # Nutzerprofil

Aufgabenstellung

Arbeite die folgenden Aufgaben Schritt für Schritt ab. Nutze KI als Co-Coder, aber schreibe den Code selbst!

Tipp

Starte mit main.py und einem einfachen Menü. Erweitere dann nach und nach. Teste jede Funktion, bevor du zur nächsten gehst.

Bronze: Das Grundgerüst

Erstelle main.py mit einem Menü, das den Nutzer nach seinem Namen fragt und drei Optionen anbietet: Begrüßung, Rechner, Beenden.

Silber: Datenstrukturen

Erweitere PyBuddy um eine To-Do-Liste und ein Nutzerprofil. Speichere die Daten in JSON.

Gold: Module & API

Strukturiere PyBuddy in Module und integriere eine API für Wetter- oder Bitcoin-Abfragen.

Didaktische Pause

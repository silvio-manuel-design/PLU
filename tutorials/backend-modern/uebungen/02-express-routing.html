Ziel

Erstelle komplexe Routen mit Parametern und Middleware in Express.

  1. Route-Parameter

    Erstelle dynamische Routen:

    app.get('/users/:id', (req, res) => { const userId = req.params.id; res.send(`User ID: ${userId}`); });

  2. Query-Parameter

    Nutze URL-Parameter für Filter:

    app.get('/search', (req, res) => { const q = req.query.q; res.send(`Suche nach: ${q}`); }); // URL: /search?q=express

  3. Middleware erstellen

    Logger-Middleware als Beispiel:

    app.use((req, res, next) => { console.log(`${new Date().toISOString()} - ${req.method} ${req.url}`); next(); });

  4. Static Files

    Serve statische Dateien:

    app.use(express.static('public'));

  5. Error Handling

    Fange Fehler ab:

    app.use((err, req, res, next) => { console.error(err.stack); res.status(500).send('Etwas ist schiefgelaufen!'); });

Side Quest U04 ~20 Min • +40 XP

Ziel

Führe komplexe SQL-Abfragen mit WHERE, ORDER BY und LIMIT aus.

  1. Datenbank vorbereiten

    Erstelle eine Tabelle products mit: id, name, price, category.

    Füge 10+ Testprodukte ein.

  2. WHERE-Klausel

    Filtere Produkte nach Preis:

    $sql = "SELECT * FROM products WHERE price > 50"; $result = $conn->query($sql);

  3. ORDER BY

    Sortiere die Ergebnisse:

    $sql = "SELECT * FROM products ORDER BY price DESC"; // ASC = aufsteigend, DESC = absteigend

  4. LIMIT

    Begrenze die Anzahl:

    $sql = "SELECT * FROM products LIMIT 5"; // Nur die ersten 5 Ergebnisse

  5. Kombination

    Alles zusammen:

    $sql = "SELECT * FROM products WHERE category = 'Elektronik' ORDER BY price ASC LIMIT 3";

  6. Anzeige formatieren

    Zeige die Ergebnisse in einer HTML-Tabelle:

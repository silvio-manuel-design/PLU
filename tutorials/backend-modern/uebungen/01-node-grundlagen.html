Ziel

Vertiefe deine Node.js-Kenntnisse mit Modulen und Dateisystem.

  1. Eigene Module erstellen

    Erstelle math.js mit Funktionen:

    exports.add = (a, b) => a + b; exports.multiply = (a, b) => a * b;

  2. Module importieren

    Nutze dein Modul in app.js:

    const math = require('./math'); console.log(math.add(5, 3));

  3. Dateisystem nutzen

    Lese eine Datei mit dem fs-Modul:

    const fs = require('fs'); const data = fs.readFileSync('text.txt', 'utf8'); console.log(data);

  4. JSON verarbeiten

    Lese und parse JSON-Daten:

    const raw = fs.readFileSync('data.json'); const obj = JSON.parse(raw); console.log(obj.name);

  5. Testen

    Führe alle Skripte aus und prüfe die Ausgaben.

Ziel

Erstelle eine vollständige CRUD-Verwaltung für Datenbankeinträge.

  1. Übersichtsseite (READ)

    Zeige alle Einträge aus der Tabelle an:

    $sql = "SELECT * FROM products"; $result = $conn->query($sql); // Zeige in Tabelle mit Bearbeiten/Löschen-Links

  2. Neuer Eintrag (CREATE)

    Formular und INSERT:

    $sql = "INSERT INTO products (name, price, category) VALUES (?, ?, ?)"; $stmt = $conn->prepare($sql); $stmt->bind_param("sds", $name, $price, $category);

  3. Bearbeiten (UPDATE)

    Formular mit vorbelegten Werten:

    $sql = "UPDATE products SET name=?, price=?, category=? WHERE id=?"; $stmt->bind_param("sdsi", $name, $price, $category, $id);

  4. Löschen (DELETE)

    Mit Sicherheitsabfrage:

    if (isset($_GET['confirm'])) { $sql = "DELETE FROM products WHERE id=?"; $stmt = $conn->prepare($sql); $stmt->bind_param("i", $id); }

  5. Navigation

    Verlinke alle Seiten:

    // Links für jede Zeile echo "Bearbeiten"; echo "Löschen";

  6. Testen

    Erstelle, bearbeite und lösche Test-Einträge.

    Prüfe, ob alle Änderungen in der Datenbank ankommen.

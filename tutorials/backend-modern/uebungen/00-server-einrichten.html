Ziel

Richte XAMPP ein und starte Apache sowie MySQL.

  1. XAMPP herunterladen

    Lade XAMPP von apachefriends.org herunter (Windows/Mac/Linux).

  2. Installation

    Installiere mit Standard-Einstellungen. Merke dir den Installationspfad (z.B. C:\xampp).

  3. Control Panel starten

    Öffne das XAMPP Control Panel als Administrator.

  4. Apache starten

    Klicke "Start" neben Apache. Der Port 80 sollte grün werden.

    http://localhost → sollte XAMPP-Seite zeigen

  5. MySQL starten

    Klicke "Start" neben MySQL. Auch hier sollte grün erscheinen.

Apache läuft noch nicht:

  1. Öffne das XAMPP Control Panel
  2. Klicke auf "Start" neben Apache
  3. Warte bis die Hintergrundfarbe grün wird
  4. Klicke dann erneut "Server-Status prüfen"

Reflexion

  • XAMPP bündelt Apache (Webserver) und MySQL (Datenbank).
  • Port 80 ist der Standard-Port für HTTP.
  • localhost = dein eigener Computer als Server.

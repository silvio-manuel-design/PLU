Ziel

Schütze deine Anwendung vor den häufigsten Sicherheitslücken.

  1. SQL-Injection verhindern

    Nie User-Input direkt in SQL-Queries einfügen.

    // UNSICHER: $query = "SELECT * FROM users WHERE id = '$id'"; // SICHER (Prepared Statements): $stmt = $conn->prepare("SELECT * FROM users WHERE id = ?"); $stmt->bind_param("i", $id);

  2. XSS verhindern

    Alle Ausgaben escapen, bevor sie im Browser angezeigt werden.

    // UNSICHER: echo $_GET['name']; // SICHER: echo htmlspecialchars($_GET['name'], ENT_QUOTES, 'UTF-8');

  3. Passwörter sicher speichern

    Nie Klartext-Passwörter speichern. Immer hashen!

    // PHP: $hash = password_hash($password, PASSWORD_DEFAULT); // Node.js (bcrypt): const hash = await bcrypt.hash(password, 10);

  4. Input validieren

    Prüfe alle Eingaben auf Typ, Länge und Format.

    // Beispiel: E-Mail validieren if (!filter_var($email, FILTER_VALIDATE_EMAIL)) { die('Ungültige E-Mail'); }

  5. Fehlermeldungen

    Im Production-Mode keine detaillierten Fehler anzeigen.

    // Stattdessen loggen: error_log("DB Error: " . $conn->error); echo "Ein Fehler ist aufgetreten.";

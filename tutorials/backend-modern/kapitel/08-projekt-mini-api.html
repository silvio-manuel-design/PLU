Ziel

Baue eine vollständige REST-API mit CRUD-Operationen.

  1. Projekt-Setup

    Erstelle einen neuen Ordner mini-api.

    Initialisiere npm und installiere Express:

    npm init -y npm install express

  2. Datenstruktur

    Erstelle ein Array als "Datenbank":

    const items = [ { id: 1, name: 'Item 1' }, { id: 2, name: 'Item 2' } ];

  3. CRUD-Routen erstellen

    Implementiere alle Operationen:

    // READ all app.get('/api/items', (req, res) => { res.json(items); }); // READ one app.get('/api/items/:id', (req, res) => { const item = items.find(i => i.id == req.params.id); item ? res.json(item) : res.status(404).send('Not found'); });

  4. CREATE & DELETE

    Füge POST und DELETE hinzu:

    // CREATE app.post('/api/items', (req, res) => { const newItem = { id: Date.now(), name: req.body.name }; items.push(newItem); res.status(201).json(newItem); }); // DELETE app.delete('/api/items/:id', (req, res) => { const index = items.findIndex(i => i.id == req.params.id); if (index > -1) { items.splice(index, 1); res.send('Deleted'); } });

  5. Testen mit Postman/cURL

    Teste alle Routen:

    GET http://localhost:3000/api/items GET http://localhost:3000/api/items/1 POST http://localhost:3000/api/items DELETE http://localhost:3000/api/items/1

  6. Glückwunsch!

    Du hast eine vollständige API gebaut.

    Das ist die Grundlage für jede moderne Web-App.

Reflexion

  • REST-APIs nutzen HTTP-Methoden: GET, POST, PUT, DELETE.
  • CRUD = Create, Read, Update, Delete.
  • Statuscodes sind wichtig: 200 OK, 201 Created, 404 Not Found.

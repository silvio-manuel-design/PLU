Ziel

Baue einen Webserver mit Express.js, der auf Anfragen antwortet.

  1. Express installieren

    Erstelle einen neuen Ordner und initialisiere npm:

    npm init -y npm install express

  2. Server-Datei erstellen

    Erstelle server.js mit dem Express-Grundgerüst:

    const express = require('express'); const app = express(); const PORT = 3000; app.listen(PORT, () => { console.log('Server läuft auf Port ' + PORT); });

  3. Erste Route erstellen

    Füge eine GET-Route hinzu:

    app.get('/', (req, res) => { res.send('Hallo von Express!'); });

  4. Server starten

    Starte den Server im Terminal:

    node server.js

    Teste im Browser: http://localhost:3000

  5. Weitere Route hinzufügen

    Erstelle eine Route für /api:

    app.get('/api', (req, res) => { res.json({ message: 'API läuft', status: 'OK' }); });

  6. Testen

    Rufe http://localhost:3000/api im Browser auf.

    Du solltest JSON-Daten sehen.

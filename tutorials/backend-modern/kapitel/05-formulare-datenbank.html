Ziel

Verbinde PHP mit einer MySQL-Datenbank und lies Daten aus.

  1. Datenbank erstellen

    Öffne phpMyAdmin (http://localhost/phpmyadmin).

    Erstelle eine neue Datenbank: backend_db

  2. Tabelle erstellen

    Erstelle eine Tabelle users mit Spalten:

    id (INT, Auto-Increment, Primary) name (VARCHAR, 100) email (VARCHAR, 100)

  3. Testdaten einfügen

    Füge 2-3 Test-Einträge über phpMyAdmin ein.

  4. PHP-Verbindung

    Erstelle db.php mit der Verbindung:

    connect_error) { die('Verbindung fehlgeschlagen'); } echo 'Verbunden!'; ?>

  5. Daten auslesen

    Erweitere die Datei mit einer Abfrage:

    $sql = "SELECT * FROM users"; $result = $conn->query($sql); while($row = $result->fetch_assoc()) { echo $row['name'] . "
    "; }

  6. Testen

    Rufe die Datei im Browser auf.

    Du solltest die Namen aus der Datenbank sehen.

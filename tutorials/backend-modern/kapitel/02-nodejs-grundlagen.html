Mission 02 ~15 Min

Ziel

Schreibe dein erstes Node.js-Programm und führe es im Terminal aus.

  1. Node.js checken

    Öffne Terminal/CMD und gib ein: node --version

    Du solltest eine Versionsnummer sehen (z.B. v18.x.x).

  2. Neue Datei erstellen

    Erstelle eine Datei namens hello.js:

    console.log('Hello Backend!'); console.log('Server startet...');

  3. Programm ausführen

    Im Terminal im gleichen Ordner:

    node hello.js

    Du solltest "Hello Backend!" sehen.

  4. Einfachen Server bauen

    Erweitere die Datei zu einem Mini-Server:

    const http = require('http'); const server = http.createServer((req, res) => { res.end('Hallo vom Server!'); }); server.listen(3000); console.log('Server läuft auf Port 3000');

  5. Server testen

    Starte den Server: node hello.js

    Öffne Browser: http://localhost:3000

    Du solltest "Hallo vom Server!" sehen.

Self-Test: Funktioniert dein Server?

Reflexion

  • Node.js führt JavaScript außerhalb des Browsers aus.
  • Ein Server lauscht auf einem Port (hier: 3000).
  • Der Browser kann den lokalen Server erreichen.

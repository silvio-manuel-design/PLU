INFO Information

Zielsetzung

Dieses Tutorial vermittelt Backend-Entwicklung mit Node.js und PHP für Schüler der HTBLA Traun im Fach Medientechnik.

Didaktisches Konzept

  • Kein Copy-Paste: Aufgaben fördern Verständnis, nicht Code-Generierung
  • Sicherheit von Anfang an: Prepared Statements, Escaping, Validierung
  • Modularer Aufbau: Jedes Kapitel baut auf dem vorherigen auf
  • Gamification: XP, Level und Missionen für Motivation
  • KI als Partner: Nutze KI zum Denken, nicht zum Abschreiben

Lizenz & Nutzung

  • ✅ Nutzen: Für Unterricht, Selbststudium, Weiterbildung
  • ✅ Anpassen: Für eigene Klassen, Schulen, Lernziele
  • ❌ Verkaufen: Nicht kommerziell nutzen
  • ❌ Plagiat: Quelle stets angeben

Entwickelt von: HTBLA Traun | Medientechnik
Prof. Dipl.-Ing. Martin Zoister, akad. BVT

Progressive Web App (PWA)

Dieses Tutorial ist als PWA verfügbar. Installiere es für Offline-Zugriff:

  • Android: Menü → "Zum Startbildschirm hinzufügen"
  • iOS: Teilen-Symbol → "Zum Home-Bildschirm"
  • Windows: Chrome/Edge → "Als App installieren"

Native Apps für Android und iOS sind in Kürze verfügbar.

Technische Hinweise

  • Alle Fortschritte werden lokal im Browser gespeichert (localStorage)
  • Keine Daten werden an externe Server übertragen
  • Classroom Mode: Für Smartboard-Nutzung aus 6-8m Entfernung

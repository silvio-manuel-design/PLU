Allowed tools

You only use what you learned in chapters 01–10. Everything else is forbidden.

Allowed

  • Variables: const and let
  • Text and numbers (strings, numbers)
  • Branches: if, else
  • Loops: for
  • Arrays and objects
  • Functions: return, parameters
  • DOM: getElementById, textContent, classList, addEventListener
  • Timing: setTimeout, Math.random(), Date.now()
  • Output: console.log, innerHTML
  • HTML/CSS: basic structure, embedded with defer

Not allowed

  • Forms — they come in chapter 11
  • External libraries and image files — you do not need them

If the AI sends you code with words from the “Not allowed” list — do not use it. Rather ask the AI: “Explain to me …”. You build it yourself.

Design guidelines

Your page is dark. Your code is in the title. The button fills most of the page.

Guidelines

  • Dark background, like the chapter pages
  • Your code in the page title, clearly visible
  • The button is big and shows its state clearly: waiting, green, too early
  • The waiting time is between 1 and 2 + your number seconds

Everything else you design freely. Surprise me.

Requirements

Tick every line only when your code really does it. At the end, print the list as a PDF.

Step by step

Six steps. Plan about 20 minutes. After each step, reload your page.

  1. 1

    Create the folder

    Create the folder uebung-10/. Inside it index.html, css/ and js/. Create css/style.css and js/main.js and link them.

  2. 2

    Skeleton and design

    Heading h1 with your code. Dark background in style.css. A big button and an element with id="output".

  3. 3

    Start handler

    On button click: setTimeout(ready, 1000 + Math.random() * (1000 + yourNumber * 1000)). Also create let isReady = false; and let start = 0;.

  4. 4

    Green and measure

    ready: set the class for green, remember isReady = true and start = Date.now().

  5. 5

    Click handler

    If isReady is false, show "Too early!". Otherwise compute Date.now() - start and round it.

  6. 6

    Output and test

    Write round and result into #output. Reload the page, play a few times, then tick the requirements.

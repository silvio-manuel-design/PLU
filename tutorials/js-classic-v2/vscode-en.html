Download

Open code.visualstudio.com and download the installer for your operating system. The default settings are enough — just click through.

Optional, right after: install the extension for your language (e.g. „German Language Pack" — Extensions icon in the sidebar → search → Install). VS Code restarts in your language.

Claim your free account & Copilot

GitHub gives verified students GitHub Pro for free — including GitHub Copilot, an AI assistant that suggests and explains code right in the editor. This course works with AI guidance; with Copilot you have the same support by your side while you write.

  • Create a GitHub account — register for free at github.com/signup (external link, opens in a new window) and confirm your e-mail.

Typical mistakes

Copilot asks for payment

Then the verification is missing or VS Code is signed in with a different account. Check your status at github.com/education and switch the account at the bottom left in VS Code.

Signing in to VS Code fails

Allow the sign-in in the browser window that opened (check the pop-up blocker) — VS Code returns on its own.

Install these extensions

  • Live Server — reloads the page in the browser on every save.
  • Prettier — formats your code cleanly, automatically on save.
  • ESLint (optional) — shows errors right in the code.

Typical mistakes

Live Server won't start

Live Server needs a file inside a folder — single files without a folder don't work. Open a folder first, then start.

I don't see my changes

Usually cache or the wrong file: don't forget to save (Ctrl+S) and check whether the browser shows the right file.

Code underlined in red

A typo — the extension helps you find the spot. Read first, then fix, don't guess.

Terminal can't find git

Then Git is missing on your machine — install it from git-scm.com, see the GitHub page.

Pro tip

Once Live Server runs and the page refreshes on save, your setup is done — you don't need more.

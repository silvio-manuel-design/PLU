Your Project Website

Required sections — the rest is yours

You present your project as your own, designed website. These six sections are required — design, colors and everything else are your call.

  • Hero — project title, subtitle, your code.
  • The project — the goal and who it is for, in two sentences.
  • Requirements — your checklist as a plain list, without ticking.
  • The build — two to three screenshots or code passages, each with one sentence of explanation.
  • Reflection — what was hard, what you learned, what you would build next.
  • GitHub link — repository with app and website.

Work with the AI

The rule: the AI explains, you build yourself. Have code explained to you — not delivered. If you take code from the AI, you must be able to explain every line.

Your starter prompt

Allowed

  • Everything from chapters 01–12 — including everything that was banned in the labs.

Not allowed

  • fetch and server code, external libraries, taking over finished programs or games.

Three check questions

  • Explain how my code stores the data — without showing me your own proposal.
  • Which part of my code is the most fragile? Explain why.
  • How would you improve my project website? Collect three ideas.

Allowed tools

You only use what you learned in chapters 01–11. Everything else is forbidden.

Allowed

  • Variables: const and let
  • Text and numbers (strings, numbers)
  • Branches: if, else
  • Loops: for
  • Arrays and objects
  • Functions: return, parameters
  • DOM: getElementById, textContent, addEventListener
  • Forms: required, type="email", minlength, submit event, preventDefault, aria-live, form.reset()
  • HTML/CSS: basic structure, embedded with defer

Not allowed

  • Regular expressions (regex) — you do not need them here
  • fetch and server code — that comes later

If the AI sends you code with words from the “Not allowed” list — do not use it. Rather ask the AI: “Explain to me …”. You build it yourself.

Design guidelines

Your page is dark. Your code is in the title. The form is the centre — friendly and clear.

Guidelines

  • Dark background, like the chapter pages
  • Your code in the page title, clearly visible
  • The three fields are listed one below the other, each with room for its error message
  • Your password field requires at least 6 + your number characters
  • Error messages are striking, success is green

Everything else you design freely. Surprise me.

Requirements

Tick every line only when your code really does it. At the end, print the list as a PDF.

Step by step

Six steps. Plan about 20 minutes. After each step, reload your page.

  1. 1

    Create the folder

    Create the folder uebung-11/. Inside it index.html, css/ and js/. Create css/style.css and js/main.js and link them.

  2. 2

    Skeleton and form

    Heading h1 with your code. Dark background. The form with three fields, required and minlength (password: 6 + your number).

  3. 3

    Error elements

    Next to each field, a <p class="error" aria-live="polite"></p> — room for the message.

  4. 4

    Submit handler

    addEventListener("submit", …) on the form. First event.preventDefault(), then check the values.

  5. 5

    Messages and success

    Write errors into the error elements. On success: form.reset() and a green confirmation text.

  6. 6

    Test and tick

    Test wrong inputs, then correct ones. Check messages and success, then tick the requirements.

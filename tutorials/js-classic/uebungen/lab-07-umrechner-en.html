Lab 07 — Mini Converter

Functions package your knowledge. You build three converters with clean returns. Time: about 30 min.

Your task

You write three small tools: Celsius to Fahrenheit, km/h to m/s, and a price formatter. Each function gets input, calculation and return — nothing more.

← Back to chapter 07

Requirements

Only tick a line when your code really does it.

Step by step

  1. Write celsiusToFahrenheit with parameter and return.
  2. Write kmhToMs and round the result.
  3. Write formatPrice returning ready text.
  4. Call all three and write the results into the HTML.
  5. Test with the values 100 °C, 50 km/h and 3.1415 €.

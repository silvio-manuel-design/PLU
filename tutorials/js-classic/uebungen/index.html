Übungen

Jedes Kapitel hat eine Übung. Du löst sie zu Hause — mit der KI an deiner Seite. Deine Lehrkraft gibt die Übung und die Deadline bekannt.

So läuft es jede Woche

  1. Deine Lehrkraft gibt die Übung bekannt. Meist eine pro Woche.
  2. Öffne das Lab und lies die Aufgabe. Unten findest du die Anforderungen.
  3. Löse die Aufgabe mit der KI. Nutze den Starter-Prompt im Lab.
  4. Prüfe den Code. Beantworte die drei Prüf-Fragen ehrlich.
  5. Lade die Datei in dein GitHub-Repo hoch. Anleitung: GitHub & Abgabe.
  6. Hake die Übung hier ab. Dann weißt du, was du schon geschafft hast.

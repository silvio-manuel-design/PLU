Allowed tools

You only use what you learned in chapters 01–09. Everything else is forbidden.

Allowed

  • Variables: const and let
  • Text and numbers (strings, numbers)
  • Branches: if, else
  • Loops: for
  • Arrays and objects
  • Functions: return, parameters
  • DOM: getElementById, textContent, classList, addEventListener
  • Output: console.log, innerHTML
  • HTML/CSS: basic structure, embedded with defer

Not allowed

  • Only the click event — other events come in chapter 10
  • Forms — they come in chapter 11

If the AI sends you code with words from the “Not allowed” list — do not use it. Rather ask the AI: “Explain to me …”. You build it yourself.

Design guidelines

Your page is dark. Your code is in the title. The button is big and inviting.

Guidelines

  • Dark background, like the chapter pages
  • Your code in the page title, clearly visible
  • The button is big, the display easy to read
  • The class is-hot has a striking colour
  • Your number appears on the page as a small hint

Everything else you design freely. Surprise me.

Requirements

Tick every line only when your code really does it. At the end, print the list as a PDF.

Step by step

Six steps. Plan about 20 minutes. After each step, reload your page.

  1. 1

    Create the folder

    Create the folder uebung-09/. Inside it index.html, css/ and js/. Create css/style.css and js/main.js and link them.

  2. 2

    Skeleton and design

    Heading h1 with your code. Dark background in style.css. A big button id="btn", a display id="count", a reset button.

  3. 3

    Counter and handler

    Create let count = 0;. With addEventListener, build a click handler: count++, then countEl.textContent = count.

  4. 4

    Hot state

    From 10 clicks, set the class is-hot — with classList.add. The colour goes into style.css.

  5. 5

    Master and reset

    From 20 clicks, show a paragraph "Click master". The reset button sets count to 0 and clears the display.

  6. 6

    Test and tick

    Reload the page: click until it gets hot. Check the reset, watch the console. Then tick the requirements.

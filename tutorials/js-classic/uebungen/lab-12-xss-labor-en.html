Allowed tools

You only use what you learned in chapters 01–12. Everything else is forbidden.

Allowed

  • Everything from chapters 01–11 — including forms and input fields
  • innerHTML — allowed here: attempt A shows the security problem
  • textContent — the protection in attempt B
  • HTML/CSS: basic structure, embedded with defer

Not allowed

  • External libraries (e.g. DOMPurify) — the lab shows the problem unprotected
  • fetch and server code — that comes later

If the AI sends you code with words from the “Not allowed” list — do not use it. Rather ask the AI: “Explain to me …”. You build it yourself.

Design guidelines

Your page is dark. Your code is in the title. The two attempts sit side by side, clearly separated.

Guidelines

  • Dark background, like the chapter pages
  • Your code in the page title, clearly visible
  • Two experiment blocks A and B, clearly separated and labelled
  • Your explanation card is written in your own words — two sentences maximum
  • Your extra shot also shows an own input containing your number

Explanation

Attempt A interprets the input as HTML — the browser executes the onerror attribute. Attempt B shows the same input as plain text — the browser executes nothing.

Extra shot

Also test <script>alert(1)</script>: modern browsers block <script> via innerHTML — but the onerror hole in attempt A stays open.

Summary

Never print foreign input with innerHTML.

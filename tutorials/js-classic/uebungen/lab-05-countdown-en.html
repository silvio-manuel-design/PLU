Lab 05 — Countdown & Tables

Build a countdown. One loop counts for you. Time: about 30 min.

Your task

You build a countdown. One loop counts down from your start number to zero. After that comes the start.

  1. Your page has three files. The files are called index.html, css/style.css and js/main.js. All three live in one folder and are linked.
  2. Your countdown has a start number. The start number is 10 + your number. Example: your number is 5 — the start number is 15. It sits in a const.
  3. A loop counts down. A for loop starts at the start number and counts to 0. On every pass the current number appears on the page — one number per line.
  4. After the loop comes the start. When the loop is done, the page shows: Start! [your code]. The console gets a closing line too.

Your two values — you need no notebook and no pen

  • Your code: your school ID + your initials, lower case, no dot. Example: 12345ms
  • Your number: the last digit of your school ID — it is inside your start number (10 + number). Example: school ID 12345 → start number 15

In the end, your code is in the page title. Your start number is your number. Your loop counts just for you. Your result is clearly yours — not the one of the person next to you.

Allowed tools

You only use what you learned in chapters 01–05. Everything else is forbidden.

Allowed

  • Everything from Lab 01–04: const, let, prompt(), Number(), arithmetic, if/else, template literals, console.log, innerHTML
  • Loops: for with a counter (i++, i--)
  • Appending text: += (also to innerHTML)

Not allowed

  • while — in this lab we stay with for
  • setInterval or waiting — the countdown runs straight through
  • Own functions — they come in chapter 07
  • Arrays — they come in chapter 06
  • Input fields and buttons with events — they come in chapters 09 and 10

If the AI sends you code with words from the “Not allowed” list — do not use it. Rather ask the AI: “Explain to me …”. You build it yourself.

Design guidelines

Your page is dark. Your code is in the title. The numbers are easy to read.

Guidelines

  • Dark background, like the chapter pages
  • Your code in the page title, clearly visible
  • Each number is on its own line, easy to read
  • The Start! line stands out: larger or a different colour

Everything else you design freely. Surprise me.

Requirements

Tick every line only when your code really does it. At the end, print the list as a PDF.

Step by step

Six steps. Plan about 20 minutes. After each step, reload your page.

  1. 1

    Create the folder

    Folder uebung-05/ with index.html, css/ and js/. Link everything.

  2. 2

    HTML skeleton

    Heading h1 with your code. An element with id="countdown".

  3. 3

    Style the page

    Dark background. Spacing and font size for #countdown.

  4. 4

    Start number

    const start = 10 + your number; — your personal start number.

  5. 5

    The loop

    for loop from start to 0, appending each number with += to #countdown.

  6. 6

    Start and test

    After the loop append Start! [code] and log the closing line with console.log. Test: reload the page and count.

Your starter prompt

Three check questions

  1. How many times does your loop run exactly — calculate it with your number.
  2. What is the difference between i-- and i++?
  3. Why does the Start! line come after the loop and not before it?

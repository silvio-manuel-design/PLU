Download

Open code.visualstudio.com and download the installer for your operating system. The default settings are enough — just click through.

Set your language

Optional but helpful: install the extension for your language (Extensions icon in the sidebar → search → Install). VS Code restarts in your language.

Install these extensions

  • Live Server — reloads the page in the browser on every save.
  • Prettier — formats your code cleanly, automatically on save.
  • ESLint (optional) — shows errors right in the code.

First test

  1. Open a folder (File → Open Folder) — e.g. a new folder js-test.
  2. Create a file index.html and write the basic structure.
  3. Include your script: <script src="main.js" defer></script> in the head.
  4. Right-click the file → „Open with Live Server" — the page opens in the browser.

Typical mistakes

Live Server won't start

Live Server needs a file inside a folder — single files without a folder don't work. Open a folder first, then start.

I don't see my changes

Usually cache or the wrong file: don't forget to save (Ctrl+S) and check whether the browser shows the right file.

Code underlined in red

A typo — the extension helps you find the spot. Read first, then fix, don't guess.

Terminal can't find git

Then Git is missing on your machine — install it from git-scm.com, see the GitHub page.

Pro tip

Once Live Server runs and the page refreshes on save, your setup is done — you don't need more.

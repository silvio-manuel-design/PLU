Herunterladen

Öffne code.visualstudio.com und lade den Installer für dein Betriebssystem herunter. Beim Installieren reichen die Standard-Einstellungen — einfach durchklicken.

Optional, direkt danach: Installiere die Extension „German Language Pack" (Extensions-Symbol in der Seitenleiste → suchen → Installieren). VS Code startet danach auf Deutsch — komfortabel, wenn dir Englisch im Weg steht.

Kostenlosen Account & Copilot sichern

GitHub schenkt verifizierten Schüler:innen GitHub Pro gratis — inklusive GitHub Copilot, einem KI-Assistenten, der dir Code vorschlägt und erklärt, direkt im Editor. Der Kurs arbeitet mit KI-Begleitung; mit Copilot hast du dieselbe Unterstützung an deiner Seite, während du schreibst.

  • GitHub-Account anlegen — auf github.com/signup (externer Link, öffnet neues Fenster) kostenlos registrieren und die E-Mail bestätigen.
  • Schüler:innen-Status verifizieren — auf github.com/education (externer Link, öffnet neues Fenster) den Status mit Schulausweis oder Schul-E-Mail freischalten → GitHub Pro gratis, Copilot inklusive.
  • In VS Code anmelden — unten links auf das Personen-Symbol klicken und mit dem GitHub-Account anmelden.
  • Copilot aktivieren — die Erweiterung „GitHub Copilot" installieren; für verifizierte Schüler:innen kostenlos.
  • Copilot als Lernbegleitung nutzen — im Copilot-Chat nach Erklärungen fragen („Warum funktioniert das?") statt Code ungeprüft zu übernehmen.

Typische Fehler

Copilot verlangt eine Zahlung

Dann fehlt die Verifizierung oder VS Code ist mit einem anderen Account angemeldet. Status auf github.com/education prüfen und in VS Code unten links den Account wechseln.

Anmeldung in VS Code schlägt fehl

Im aufgegangenen Browserfenster die Anmeldung bei GitHub erlauben (Popup-Blocker prüfen) — danach kehrt VS Code von allein zurück.

Diese Extensions installieren

  • Live Server — aktualisiert die Seite im Browser bei jeder Speicherung.
  • Prettier — formatiert deinen Code sauber, automatisch beim Speichern.
  • ESLint (optional) — zeigt Fehler direkt im Code an.

Erster Test

  1. 1

    Ordner öffnen

    Datei → Ordner öffnen — z. B. einen neuen Ordner js-test.

  2. 2

    Datei anlegen

    Datei index.html anlegen und das Grundgerüst schreiben.

  3. 3

    Skript einbinden

    <script src="main.js" defer></script> im head einfügen.

  4. 4

    Live starten

    Rechtsklick auf die Datei → „Open with Live Server" — die Seite öffnet sich im Browser.

Typische Fehler

Live Server startet nicht

Live Server braucht eine Datei in einem Ordner — einzelne Dateien ohne Ordner gehen nicht. Ordner öffnen, dann starten.

Änderungen sehe ich nicht

Meist Cache oder die falsche Datei: Speichern nicht vergessen (Strg+S) und prüfen, ob der Browser die richtige Datei zeigt.

Code rot unterkringelt

Ein Tippfehler — die Extension hilft dir, die Stelle anzusehen. Erst lesen, dann korrigieren, nicht raten.

Terminal findet git nicht

Dann fehlt Git auf dem Rechner — Installation über git-scm.com, Anleitung auf der GitHub-Seite.

Profi-Tipp

Wenn Live Server läuft und die Seite sich beim Speichern selbst aktualisiert, ist dein Setup fertig — mehr brauchst du nicht.

Herunterladen

Öffne code.visualstudio.com und lade den Installer für dein Betriebssystem herunter. Beim Installieren reichen die Standard-Einstellungen — einfach durchklicken.

Deutsch einstellen

Optional, aber hilfreich: Installiere die Extension „German Language Pack" (Extensions-Symbol in der Seitenleiste → suchen → Install). VS Code startet danach auf Deutsch.

Diese Extensions installieren

  • Live Server — aktualisiert die Seite im Browser bei jeder Speicherung.
  • Prettier — formatiert deinen Code sauber, automatisch beim Speichern.
  • ESLint (optional) — zeigt Fehler direkt im Code an.

Erster Test

  1. Ordner öffnen (Datei → Ordner öffnen) — z. B. einen neuen Ordner js-test.
  2. Datei index.html anlegen, Grundgerüst schreiben.
  3. Einbinden: <script src="main.js" defer></script> im head.
  4. Rechtsklick auf die Datei → „Open with Live Server" — die Seite öffnet sich im Browser.

Typische Fehler

Live Server startet nicht

Live Server braucht eine Datei in einem Ordner — einzelne Dateien ohne Ordner gehen nicht. Ordner öffnen, dann starten.

Änderungen sehe ich nicht

Meist Cache oder die falsche Datei: Speichern nicht vergessen (Strg+S) und prüfen, ob der Browser die richtige Datei zeigt.

Code rot unterkringelt

Ein Tippfehler — die Extension hilft dir, die Stelle anzusehen. Erst lesen, dann korrigieren, nicht raten.

Terminal findet git nicht

Dann fehlt Git auf dem Rechner — Installation über git-scm.com, Anleitung auf der GitHub-Seite.

Profi-Tipp

Wenn Live Server läuft und die Seite sich beim Speichern selbst aktualisiert, ist dein Setup fertig — mehr brauchst du nicht.

🛠️ Setup für Schüler:innen – JavaScript-Tutorial

1. Lade das gesamte Verzeichnis herunter (z. B. über Schulserver)
2. Öffne den ORDNER „js-tutorial“ in VS Code (niemals nur eine Datei!)
3. Installiere die Erweiterung „Live Server“ (Ritwick Dey)
4. Klicke rechts unten in der Statusleiste auf „Go Live“ – fertig!

> ⚠️ Warnung: Ohne Live Server funktionieren externe JS/CSS-Dateien NICHT!

💡 Tipp: Nutze die Tastenkombinationen aus der vscode.html-Seite –
         sie beschleunigen dein Coding erheblich!

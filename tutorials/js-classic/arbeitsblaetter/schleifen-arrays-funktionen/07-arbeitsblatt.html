Aufgabe 4 (7 Punkte)

Eine KI generiert folgende Funktion, um ein Element an einer bestimmten Position einzufügen:

function einfuegen(arr, index, wert) {
  for (let i = arr.length; i > index; i--) {
    arr[i] = arr[i - 1];
  }
  arr[index] = wert;
  return arr;
}

a) Warum ist diese manuelle Verschiebung fehleranfällig? (2 P)
b) Was passiert, wenn index größer als arr.length ist? (2 P)
c) Wie könnte man die Aufgabe sicherer mit einer Array-Methode lösen? Zeige den korrekten Aufruf. (3 P)

Aufgabe 5 (7 Punkte)

Ein Mitschüler möchte alle Positionen eines Werts in einem Array finden. Sein Code:

function findeAlle(arr, gesucht) {
  let ergebnis = [];
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === gesucht) {
      ergebnis.push(i);
    }
  }
  return ergebnis;
}

a) Warum ist diese Funktion robust gegenüber leeren Arrays oder nicht gefundenen Werten? (2 P)
b) Was gibt die Funktion zurück, wenn der Wert nicht vorkommt? Ist das sinnvoll? (2 P)
c) Warum ist es besser, Indizes zurückzugeben – und nicht die Werte selbst? (3 P)

Thema: Schleifen, Arrays, Funktionen

Aufgabe 1 (2 P)

Ohne sichere Abbruchbedingung führt while (true) zu einer Endlosschleife, die das Programm einfrieren lässt. Der Abbruch muss innerhalb des Schleifenkörpers mit break erfolgen – das ist schwer zu überblicken.

Aufgabe 2 (2 P)

Das Array wird geleert: alle Elemente werden entfernt, length ist danach 0. Der Speicher wird (meist) freigegeben.

Aufgabe 3 (2 P)

Der Name findeIndex macht klar, dass ein Index (Zahl) zurückgegeben wird – nicht das Element selbst. Das vermeidet Missverständnisse und verbessert die Lesbarkeit.

Aufgabe 4 (7 P)

a) Manuelle Index-Manipulation ist fehleranfällig: Off-by-one-Fehler, falsche Grenzen, fehlende Längenprüfung. (2 P)
b) Zwischen dem ursprünglichen Ende und index entstehen leere Slots (undefined), was zu unerwartetem Verhalten führt. (2 P)
c) 

function einfuegen(arr, index, wert) {
  arr.splice(index, 0, wert);
  return arr;
}
(3 P)

Aufgabe 5 (7 P)

a) Die Schleife läuft 0-mal bei leerem Array → gibt leeres Ergebnis zurück. Bei nicht gefundenem Wert wird nichts hinzugefügt → leeres Array = klare Aussage. (2 P)
b) Gibt ein leeres Array [] zurück – das ist sinnvoll: „Keine Vorkommen gefunden“. (2 P)
c) Indizes erlauben es, das Element später zu ändern, zu löschen oder seine Position zu nutzen. Der Wert allein sagt nichts über das Array aus (z. B. bei Duplikaten). (3 P)

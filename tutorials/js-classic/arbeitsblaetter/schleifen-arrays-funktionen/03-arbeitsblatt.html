Aufgabe 4 (7 Punkte)

Eine KI generiert folgende Funktion, um ein Array rückwärts auszugeben:

function ausgabeRueckwaerts(arr) {
  for (let i = arr.length; i >= 0; i--) {
    console.log(arr[i]);
  }
}

Aufgabe 5 (7 Punkte)

Ein Mitschüler möchte prüfen, ob ein Array nur gerade Zahlen enthält. Seine Funktion:

function nurGerade(zahlen) {
  for (let i = 0; i < zahlen.length; i++) {
    if (zahlen[i] % 2 !== 0) {
      return false;
    }
  }
  return true;
}

a) Warum ist diese Logik effizient? (2 P)
b) Warum ist es besser, return true nach der Schleife zu platzieren – und nicht innerhalb? (3 P)
c) Was gibt die Funktion bei einem leeren Array zurück – und ist das sinnvoll? Begründe. (2 P)

Thema: Schleifen, Arrays, Funktionen

Aufgabe 1 (2 P)

Weil arr.length die Anzahl, nicht den höchsten Index, angibt. Bei i = arr.length ist der Zugriff arr[arr.length] = undefined.

Aufgabe 2 (2 P)

push gibt die neue Länge des Arrays zurück (hier: 4), nicht das Array selbst. Viele erwarten das veränderte Array – daher überraschend.

Aufgabe 3 (2 P)

const signalisiert, dass der Wert konstant bleibt – verbessert Lesbarkeit, verhindert versehentliche Änderungen und hilft beim Debugging.

Aufgabe 4 (7 P)

a) arr[arr.length] = undefined, weil der Index außerhalb des gültigen Bereichs liegt. (2 P)
b) Es wird ein zusätzliches undefined am Anfang ausgegeben – und das letzte echte Element erscheint nicht am Ende. (2 P)
c) 

for (let i = arr.length - 1; i >= 0; i--) {

Aufgabe 5 (7 P)

a) Die Schleife bricht sofort ab, sobald eine ungerade Zahl gefunden wird – spart unnötige Durchläufe. (2 P)
b) Nur wenn alle Elemente geprüft wurden und keine ungerade Zahl gefunden wurde, darf true zurückgegeben werden. In der Schleife wäre es zu früh. (3 P)
c) Gibt true zurück. Das ist logisch: Ein leeres Array enthält keine ungeraden Zahlen → Aussage „nur gerade“ ist formal erfüllt („leere Wahrheit“). (2 P)

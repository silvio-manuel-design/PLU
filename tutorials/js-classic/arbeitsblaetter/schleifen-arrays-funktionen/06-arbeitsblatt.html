Aufgabe 4 (7 Punkte)

Eine KI schlägt folgende Funktion vor, um alle ungeraden Zahlen zu entfernen:

function entferneUngerade(arr) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] % 2 !== 0) {
      arr.splice(i, 1);
    }
  }
  return arr;
}

Thema: Schleifen, Arrays, Funktionen

Aufgabe 1 (2 P)

for...in iteriert über alle aufzählbaren Eigenschaften – auch über nicht-numerische (z. B. selbst hinzugefügte). Außerdem liefert es Strings, keine Zahlen. Die klassische for-Schleife ist präzise und zuverlässig für indizierte Arrays.

Aufgabe 2 (2 P)

pop() gibt das letzte Element zurück (hier: 3) und verringert die Array-Länge um 1 (von 3 auf 2).

Aufgabe 3 (2 P)

Damit bleibt das Original-Array unverändert – die Funktion hat keine Seiteneffekte, ist testbar und wiederverwendbar.

Aufgabe 4 (7 P)

a) Beim Entfernen rutscht jedes nachfolgende Element nach links – der Index i überspringt dann das nächste Element. (2 P)
b) Beispiel: [1, 3, 4] → bei i=0 wird 1 entfernt → Array wird [3, 4], aber i wird zu 1 → 3 wird übersprungen. (2 P)
c) 

function entferneUngerade(arr) {
  let ergebnis = [];
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] % 2 === 0) {
      ergebnis.push(arr[i]);
    }
  }
  return ergebnis;
}
(3 P)

Aufgabe 5 (7 P)

a) Arrays sind Objekte – der Vergleich prüft die Speicherreferenz, nicht den Inhalt. Zwei separate Arrays sind nie identisch im Speicher. (2 P)
b) 

function arraysGleich(a, b) {
  if (a.length !== b.length) return false;
  for (let i = 0; i < a.length; i++) {
    if (a[i] !== b[i]) return false;
  }
  return true;
}
(3 P)
c) Wenn die Längen unterschiedlich sind, können die Arrays nicht gleich sein – die Elementprüfung wäre unnötig und könnte zu Fehlern führen (z. B. Zugriff auf undefined). (2 P)

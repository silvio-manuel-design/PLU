Aufgabe 4 (7 Punkte)

Eine KI schlägt folgende Funktion vor, um Duplikate zu entfernen:

function entferneDuplikate(arr) {
  let ergebnis = [];
  for (let i = 0; i < arr.length; i++) {
    if (ergebnis.indexOf(arr[i]) === -1) {
      ergebnis.push(arr[i]);
    }
  }
  return ergebnis;
}

a) Warum ist diese Lösung korrekt, aber ineffizient bei großen Arrays? (2 P)
b) Warum funktioniert sie trotzdem gut bei kleinen Arrays im Unterrichtskontext? (2 P)
c) Nenne eine effizientere Alternative mit modernem JavaScript (ohne Schleife). (3 P)

Aufgabe 5 (7 Punkte)

Ein Mitschüler möchte prüfen, ob ein Array streng aufsteigend sortiert ist (jedes Element kleiner als das nächste). Sein Code:

function istAufsteigend(arr) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] >= arr[i + 1]) {
      return false;
    }
  }
  return true;
}

a) Warum führt dieser Code zu einem Fehler beim letzten Element? (2 P)
b) Wie muss die Schleifenbedingung korrigiert werden? (2 P)
c) Was gibt die Funktion bei einem Array mit einem oder keinem Element zurück – und ist das sinnvoll? Begründe. (3 P)

Aufgabe 5 (7 P)

a) Bei i = arr.length - 1 greift arr[i + 1] auf arr[arr.length] zu = undefined. Vergleich mit Zahl ergibt false – logisch falsch. (2 P)
b) Schleife muss laufen: for (let i = 0; i < arr.length - 1; i++) (2 P)
c) Bei leerem Array: Schleife wird nicht betreten → gibt true zurück.
Bei einem Element: ebenso true.
Das ist sinnvoll: Ein leeres oder eintelliges Array ist „trivialerweise“ sortiert. (3 P)

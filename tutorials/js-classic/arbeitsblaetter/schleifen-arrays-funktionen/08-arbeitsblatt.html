Aufgabe 4 (7 Punkte)

Eine KI schlägt folgende Funktion vor, um ein Array zu „leeren“ und neu zu befüllen:

function leerenUndBefuellen(arr, neueWerte) {
  arr = [];
  for (let wert of neueWerte) {
    arr.push(wert);
  }
  return arr;
}

a) Warum hat diese Funktion keinen Effekt auf das ursprüngliche Array außerhalb der Funktion? (2 P)
b) Was gibt die Funktion zurück – und warum hilft das nicht, wenn man das Original ändern möchte? (2 P)
c) Schreibe eine Version, die das übergebene Array tatsächlich leert und befüllt. (3 P)

Aufgabe 5 (7 Punkte)

Ein Mitschüler möchte prüfen, ob ein Array mindestens ein Element enthält, das eine Bedingung erfüllt (z. B. gerade Zahl). Sein Code:

function hatErfuellt(arr, bedingung) {
  for (let i = 0; i < arr.length; i++) {
    if (bedingung(arr[i])) {
      return true;
    }
  }
  return false;
}

a) Warum ist es clever, eine Funktion als Parameter zu übergeben? (2 P)
b) Wie könntest du diese Funktion aufrufen, um zu prüfen, ob mindestens eine gerade Zahl vorhanden ist? (3 P)
c) Warum ist der Name hatErfuellt besser als pruefe? (2 P)

Aufgabe 1 (2 P)

Der Code wird lesbarer und kürzer – man muss sich nicht um Indizes kümmern. Außerdem gibt es keine Gefahr von Off-by-one-Fehlern.

Aufgabe 2 (2 P)

arr = [] erstellt ein neues Array – die alte Referenz bleibt unverändert für andere, die sie halten.
arr.length = 0 leert das bestehende Array – alle, die die Referenz haben, sehen die Änderung.

Aufgabe 3 (2 P)

Die Funktion wird universell: Man kann beliebige Umwandlungen (z. B. verdoppeln, in Großbuchstaben, runden) übergeben – ohne den Code zu ändern.

Aufgabe 4 (7 P)

a) arr = [] ändert nur die lokale Variable innerhalb der Funktion. Die ursprüngliche Referenz außerhalb bleibt unberührt. (2 P)
b) Gibt ein neues Array zurück – aber wer das Original ändern will, müsste meinArray = leerenUndBefuellen(meinArray, ...) schreiben. Direkte Änderung ist nicht möglich. (2 P)
c) 

function leerenUndBefuellen(arr, neueWerte) {
  arr.length = 0; // Original leeren
  for (let wert of neueWerte) {
    arr.push(wert);
  }
  return arr; // optional
}
(3 P)

Aufgabe 5 (7 P)

a) Man kann beliebige Bedingungen (gerade, positiv, Stringlänge > 5) einsetzen – ohne die Funktion zu ändern. (2 P)
b) 

hatErfuellt([1, 3, 5], x => x % 2 === 0); // false
hatErfuellt([1, 2, 3], x => x % 2 === 0); // true
(3 P)
c) hatErfuellt beschreibt klar das Ergebnis (boolscher Wert: ja/nein). pruefe ist vage – was wird geprüft? Was wird zurückgegeben? (2 P)

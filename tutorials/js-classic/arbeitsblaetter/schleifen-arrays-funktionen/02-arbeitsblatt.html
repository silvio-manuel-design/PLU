Aufgabe 4 (7 Punkte)

Eine KI schlägt folgende Funktion vor, um ein Array zu verdoppeln:

function verdopple(arr) {
  for (let i = 0; i < arr.length; i++) {
    arr[i] = arr[i] * 2;
  }
}

a) Was ist der Nebeneffekt dieser Funktion? (2 P)
b) Warum ist das in größeren Programmen problematisch? (2 P)
c) Schreibe eine reine Funktion, die ein neues verdoppeltes Array zurückgibt – ohne das Original zu verändern. (3 P)

Aufgabe 5 (7 Punkte)

Gegeben ist ein Array mit Zahlen: [10, -5, 0, 8].
Ein Schüler bittet eine KI: „Finde die kleinste Zahl.“ Die KI antwortet:

function findeKleinste(liste) {
  let min = 0;
  for (let i = 0; i < liste.length; i++) {
    if (liste[i] < min) min = liste[i];
  }
  return min;
}

a) Warum liefert diese Funktion bei [10, -5, 0, 8] das richtige Ergebnis – bei [3, 7, 2] aber nicht? (3 P)
b) Wie müsste min initialisiert werden, damit es immer funktioniert? (2 P)
c) Warum ist es besser, liste[0] als Startwert zu nutzen? (2 P)

Aufgabe 1 (2 P)

Weil Arrays bei Index 0 beginnen. Bei n Elementen ist der letzte Index n−1. arr.length gibt die Anzahl, nicht den letzten Index, zurück.

Aufgabe 2 (2 P)

push erhöht die Länge um 1 (fügt am Ende hinzu). arr[0] = 5 ändert nur ein bestehendes Element – die Länge bleibt gleich (sofern Index bereits existiert).

Aufgabe 3 (2 P)

Die Logik wird wiederverwendbar, testbar und entkoppelt von anderen Code-Teilen. Man vermeidet Code-Duplikation.

Aufgabe 4 (7 P)

a) Die Funktion verändert das Original-Array (Seiteneffekt). (2 P)
b) Andere Teile des Programms, die das Array nutzen, sehen plötzlich veränderte Werte – schwer zu debuggen. (2 P)
c) 

function verdopple(arr) {
  let neu = [];
  for (let i = 0; i < arr.length; i++) {
    neu.push(arr[i] * 2);
  }
  return neu;
}
(3 P)

Aufgabe 5 (7 P)

a) Weil das Array negative Zahlen enthält, und 0 zufällig größer als die kleinste Zahl ist. Bei [3,7,2] sind alle Zahlen > 0, also bleibt min = 0 – was falsch ist. (3 P)
b) let min = liste[0]; (2 P)
c) So funktioniert es auch bei Arrays mit nur positiven oder nur negativen Zahlen – unabhängig vom Vorzeichen. (2 P)

Aufgabe 4 (7 Punkte)

Eine KI schlägt folgende Funktion vor, um die Summe aller positiven Zahlen zu berechnen:

function summePositiv(arr) {
  let sum = 0;
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] > 0) sum += arr[i];
  }
  return sum;
}

a) Warum ist diese Funktion bereits gut strukturiert? Nenne zwei Gründe. (2 P)
b) Was passiert, wenn das Array leer ist oder keine positiven Zahlen enthält? (2 P)
c) Erweitere die Funktion so, dass sie auch mit nicht-numerischen Werten (z. B. Strings) umgehen kann, ohne zu crashen. (3 P)

Aufgabe 5 (7 Punkte)

Ein Mitschüler möchte ein Array in zwei Hälften teilen – bei ungerader Länge soll das mittlere Element weggelassen werden. Sein Code:

function teileMitte(arr) {
  let mitte = Math.floor(arr.length / 2);
  let links = arr.slice(0, mitte);
  let rechts = arr.slice(mitte + 1);
  return [links, rechts];
}

a) Warum ist Math.floor hier sinnvoll? (2 P)
b) Was gibt die Funktion bei [1, 2, 3, 4, 5] zurück? (2 P)
c) Warum ist die Verwendung von slice sicherer als manuelles Kopieren mit einer Schleife? (3 P)

Aufgabe 1 (2 P)

Obwohl moderne JS-Engines das oft optimieren, ist es prinzipiell ineffizient: length ist eine Eigenschaft, deren Zugriff (theoretisch) Zeit kostet. Besser: for (let i = 0, len = arr.length; i < len; i++).

Aufgabe 2 (2 P)

shift() gibt das erste Element zurück (hier: 1) und verringert die Länge um 1 (von 3 auf 2).

Aufgabe 3 (2 P)

Die Funktion ist wiederverwendbar, isoliert und testbar. Globale Variablen erzeugen Abhängigkeiten, erschweren das Debugging und verhindern parallele Nutzung.

Aufgabe 4 (7 P)

a) – Keine Seiteneffekte (gibt nur einen Wert zurück).
– Klare Aufgabe, guter Name, nutzt Parameter. (2 P)
b) Gibt 0 zurück – das ist korrekt: Summe von nichts ist 0. (2 P)
c) 

function summePositiv(arr) {
  let sum = 0;
  for (let i = 0; i < arr.length; i++) {
    if (typeof arr[i] === 'number' && arr[i] > 0) {
      sum += arr[i];
    }
  }
  return sum;
}
(3 P)

Aufgabe 5 (7 P)

a) Math.floor rundet ab – bei ungerader Länge (z. B. 5 → 2.5 → 2) erhält man den Index des mittleren Elements. (2 P)
b) Gibt [[1, 2], [4, 5]] zurück – das mittlere Element 3 wird übersprungen. (2 P)
c) slice ist eine getestete, robuste Methode – sie vermeidet Off-by-one-Fehler, Index-Fehler und ist lesbarer als manuelle Schleifen. (3 P)

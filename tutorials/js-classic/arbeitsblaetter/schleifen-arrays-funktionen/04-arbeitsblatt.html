Aufgabe 4 (7 Punkte)

Eine KI schlägt folgende Funktion vor, um die Anzahl negativer Zahlen in einem Array zu zählen:

let zaehler = 0;
function zaehleNegative(werte) {
  for (let i = 0; i < werte.length; i++) {
    if (werte[i] < 0) zaehler++;
  }
  return zaehler;
}

a) Warum ist die Verwendung einer globalen Variable zaehler problematisch? (2 P)
b) Was passiert, wenn man die Funktion zweimal hintereinander aufruft? (2 P)
c) Schreibe die Funktion so um, dass sie ohne globale Variable auskommt und bei jedem Aufruf korrekt zählt. (3 P)

Aufgabe 5 (7 Punkte)

Ein Mitschüler möchte ein Array kopieren, um es zu verändern – ohne das Original zu beeinflussen. Sein Versuch:

function verarbeiteArray(original) {
  let kopie = original;
  for (let i = 0; i < kopie.length; i++) {
    kopie[i] = kopie[i] * 10;
  }
  return kopie;
}

a) Warum verändert diese Funktion trotzdem das Original-Array? (3 P)
b) Welche Methode (oder Syntax) kann man verwenden, um eine echte Kopie eines Arrays zu erstellen? (2 P)
c) Schreibe die Funktion korrekt mit einer flachen Kopie des Arrays. (2 P)

Thema: Schleifen, Arrays, Funktionen

Aufgabe 1 (2 P)

Ohne let wird i eine globale Variable. Das kann zu Konflikten mit anderen Schleifen oder Funktionen führen – schwer zu debuggen.

Aufgabe 2 (2 P)

arr.push(3) verändert das bestehende Array (erlaubt bei const, da die Referenz gleich bleibt).
arr = [1,2,3] versucht, die Referenz zu ersetzen – das geht bei const nicht und führt zu einem Fehler.

Aufgabe 3 (2 P)

Funktionen ohne Seiteneffekte sind vorhersagbar, testbar und wiederverwendbar. Sie hängen nur von ihren Parametern ab – nicht vom Programmzustand.

Aufgabe 4 (7 P)

a) Die globale Variable bleibt zwischen Funktionsaufrufen erhalten → Werte „akkumulieren“ sich. (2 P)
b) Beim zweiten Aufruf beginnt zaehler nicht bei 0, sondern beim Ergebnis des ersten Aufrufs → falsches Ergebnis. (2 P)
c) 

function zaehleNegative(werte) {
  let zaehler = 0;
  for (let i = 0; i < werte.length; i++) {
    if (werte[i] < 0) zaehler++;
  }
  return zaehler;
}
(3 P)

Aufgabe 5 (7 P)

a) let kopie = original kopiert nur die Referenz, nicht die Inhalte. Beide Variablen zeigen auf dasselbe Array im Speicher. (3 P)
b) Z. B. let kopie = [...original]; oder let kopie = original.slice(); (2 P)
c) 

function verarbeiteArray(original) {
  let kopie = [...original];
  for (let i = 0; i < kopie.length; i++) {
    kopie[i] = kopie[i] * 10;
  }
  return kopie;
}
(2 P)

Aufgabe 4 (7 Punkte)

Eine KI generiert folgende Funktion, um das größte Element eines Arrays zu finden:

function maxElement(arr) {
  let max = -Infinity;
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] > max) max = arr[i];
  }
  return max;
}

a) Warum ist -Infinity eine sichere Wahl für die Initialisierung? (2 P)
b) Was gibt die Funktion zurück, wenn das Array leer ist? Ist das sinnvoll? (2 P)
c) Erweitere die Funktion so, dass sie bei einem leeren Array einen Fehler wirft oder eine klare Rückmeldung gibt. (3 P)

function kehreUm(arr) {

    neuesArray.push(arr[i]);

a) Warum ist dieser Ansatz sicher im Vergleich zur Verwendung von reverse()? (2 P)
b) Warum ist die Schleife von arr.length - 1 bis 0 korrekt? (2 P)

✅ Musterlösung – Arbeitsblatt 5

Thema: Schleifen, Arrays, Funktionen

Aufgabe 1 (2 P)

Bei einem leeren Array ist arr.length = 0, also arr.length - 1 = -1. Die Bedingung i <= -1 ist nie erfüllt → Schleife wird übersprungen. Der eigentliche Risikofall ist selten – aber der Hinweis dient dem Bewusstsein für Grenzfälle.

Aufgabe 2 (2 P)

JavaScript erstellt ein Array mit 101 Elementen: 100 leere Stellen („leere Slots“) und an Index 100 den Wert "Test". Die Länge wird 101. Dies ist ineffizient und kann zu unerwartetem Verhalten führen.

Aufgabe 3 (2 P)

liste ist ein semantisch klarerer Name – Arrays dienen oft als geordnete Listen. Der Name beschreibt die Rolle, nicht nur den Datentyp – das verbessert Lesbarkeit und Wartbarkeit.

Aufgabe 4 (7 P)

a) -Infinity ist kleiner als jede Zahl – daher wird das erste Element immer übernommen, egal wie klein. (2 P)
b) Gibt -Infinity zurück. Das ist irreführend – ein leeres Array hat kein Maximum. (2 P)
c) 

function maxElement(arr) {
  if (arr.length === 0) {
    throw new Error("Array ist leer");
    // oder: return null;
  }
  let max = -Infinity;
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] > max) max = arr[i];
  }
  return max;
}
(3 P)

Aufgabe 5 (7 P)

a) reverse() verändert das Original-Array (Seiteneffekt). Diese Funktion erstellt eine neue Kopie → Original bleibt unberührt. (2 P)
b) Der letzte gültige Index ist arr.length - 1; herunterzählen bis 0 erfasst alle Elemente genau einmal. (2 P)
c) 

function kehreUm(arr) {
  let neuesArray = new Array(arr.length);
  for (let i = 0; i < arr.length; i++) {
    neuesArray[i] = arr[arr.length - 1 - i];
  }
  return neuesArray;
}
(3 P)

✅ Musterlösung – Arbeitsblatt 12

Thema: Schleifen, Arrays, Funktionen

Aufgabe 1 (2 P)

Weil der Index bei 0 beginnt → erstes Element = Index 0. arr[-1] existiert nicht → gibt undefined zurück (kein Fehler, aber kein gültiges Element).

Aufgabe 2 (2 P)

„Veränderlich“ = Inhalt kann geändert werden, ohne neue Referenz. Bei Funktionen mit Seiteneffekten wird das Original-Array verändert → andere Teile des Programms sehen unerwartete Änderungen.

Aufgabe 3 (2 P)

Weil sie einmal geschrieben, aber oft aufgerufen werden können. Parameter ermöglichen unterschiedliche Eingaben → gleiche Logik, verschiedene Ergebnisse. → W3Schools: „You can use the same code with different arguments.“

Aufgabe 4 (7 P)

a) – original = ["X", "Y"]
– kopie1 = original → beide zeigen auf dasselbe Array
– kopie1.push("D") → original = ["X", "Y", "D"]
– kopie2 = original.slice() → neue Kopie
– kopie2.pop() → kopie2 = ["X", "Y"], original bleibt unverändert
(3 P)
b) Weil die Funktion das Original-Array verändern könnte – unbeabsichtigt für den Aufrufer. (2 P)
c) Zitat: „Arrays sind veränderlich – const verhindert nur Neuzuweisung!“ (2 P)

Aufgabe 5 (7 P)

a) Durch Closure: Die innere Funktion behält Zugriff auf Variablen der äußeren Funktion, auch nach deren Beendigung. (2 P)
b) Prompt: „Erkläre, warum jede Instanz einer Zähler-Fabrik in JavaScript ihren eigenen Zähler-Wert speichert – und wie Closure diesen Zustand erhält.“ (3 P)
c) Lokale Variablen sind normalerweise nach Funktionsende weg. Closure „fängt“ sie ein und macht sie über die innere Funktion zugänglich – obwohl sie technisch lokal sind. → W3Schools: „Local variables can only be accessed from within the function.“ (2 P)

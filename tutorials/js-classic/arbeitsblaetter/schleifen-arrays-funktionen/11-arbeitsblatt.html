✅ Musterlösung – Arbeitsblatt 11

Thema: Schleifen, Arrays, Funktionen

Aufgabe 1 (2 P)

„Zero-indexed“ bedeutet: Der erste Index ist 0, nicht 1. Bei n Elementen ist der letzte Index n−1. arr.length gibt n zurück → arr[n] existiert nicht → undefined.

Aufgabe 2 (2 P)

Ein Taschenrechner gibt ein Ergebnis zurück – er verändert nichts außerhalb. Ohne return gibt die Funktion undefined zurück – das Ergebnis geht verloren.

Aufgabe 3 (2 P)

const verhindert nur die Neuzuweisung der Referenz – nicht die Veränderung des Inhalts. push ändert das Array, weist aber keine neue Referenz zu.

Aufgabe 4 (7 P)

a) Tabelle z. B.:
– Schritt 1: arr.length = 2 → nicht leer
– Schritt 2: Rückgabe arr[1] = 20
(3 P)
b) null signalisiert bewusst „kein Wert“ – undefined könnte ein Fehler sein. (2 P)
c) Zitat aus JS-Tutorial, Kapitel 6: „Verwende .length in Schleifen – nie feste Zahlen!“ ODER „Arrays sind veränderlich – const verhindert nur Neuzuweisung!“ (2 P)

Aufgabe 5 (7 P)

a) Weil sie ein neues Array erstellt – das Original bleibt unberührt. Bei Variante A wird das Original verändert. (2 P)
b) Beispiel-Prompt: „Erkläre, wie man eine Funktion schreibt, die ein Array erweitert, ohne das Original zu verändern – und warum das wichtig ist.“ (3 P)
c) W3Schools: „Functions are reusable block of code“. return ermöglicht, das Ergebnis weiterzuverwenden – z. B. in Berechnungen oder anderen Funktionen. (2 P)

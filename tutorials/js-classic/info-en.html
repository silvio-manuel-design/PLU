The 12-chapter path

01

Introduction & Output

Include it, print it: the web's third pillar.

02

Variables & Data Types

Remember what your program knows: name values, store them, read them correctly.

03

Operators

Calculate, compare, combine: the tools that turn values into decisions.

04

Conditions

If this, then that: let programs make decisions and react to situations.

05

Loops

Repeat without getting tired: leave repetition to the computer.

06

Arrays: Lists & Collections

Many values, one variable: build lists, loop through them, use the data.

07

Functions

Write it once, use it everywhere: think in building blocks.

08

Objects

Describe real things: collect, read and change properties.

09

The DOM

JavaScript meets HTML: read pages, change them, react to clicks.

10

Events & Interaction

Clicks, keys, input: your page reacts — to everything the user does.

11

Forms & Validation

Collect data cleanly: build forms, validate input, show friendly errors.

12

Security & Common Attacks

Never trust input: understand XSS, validate, build safely.

What you can do at the end

  • Make websites interactive with JavaScript.
  • Write variables, loops and functions safely.
  • Change the page with the DOM and react to input.
  • Validate forms and build them securely.
  • Version and submit your own project with GitHub.

For teachers

The course works for self-study AND in the classroom. Worksheets, a print view per chapter and honest progress don't replace a human — but they lighten the load. Set up the GitHub submission with the guide „GitHub in the classroom" in 30 minutes.

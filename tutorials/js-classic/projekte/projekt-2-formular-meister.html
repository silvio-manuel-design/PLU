Formular-Meister

Baue ein Anmeldeformular, das alles prüft. Fehlermeldungen erscheinen direkt am Feld. Zeit: ca. 90 Min.

Deine Aufgabe

Ein Anmeldeformular mit vier Feldern: Name, E-Mail, Passwort und Alter. Beim Absenden prüft JavaScript jedes Feld. Gefundene Fehler erscheinen als Text unter dem Feld. Erst ein fehlerfreies Formular wird abgeschickt.

← Zurück zu den Projekten

Anforderungen

Hake jede Zeile erst ab, wenn dein Code es wirklich tut.

Schritt für Schritt

  1. Lege projekt-2-formular-meister.html an. Baue das Formular mit Labels und einem Absende-Button.

  2. Fange das submit-Event ab und stoppe es mit preventDefault.

  3. Prüfe das Namensfeld. Zeige eine Fehlermeldung unter dem Feld.
  4. Prüfe die E-Mail auf genau ein @ und einen Punkt danach.
  5. Prüfe das Passwort auf mindestens acht Zeichen.
  6. Prüfe das Alter auf eine Zahl größer null.
  7. Bei Fehlern: Meldungen anzeigen, Absenden blockieren. Ohne Fehler: Erfolgsmeldung zeigen.
  8. Teste jeden Fehlertyp einzeln. Dann ein fehlerfreies Formular.
  9. Frage die KI nach einer Verbesserung. Setze genau einen Vorschlag um.

Arbeite mit der KI

Regel: Die KI schreibt gern Validierung. Du musst jede Bedingung erklären können.

  • Warum reicht ein einfaches includes('@') nicht für E-Mails?
  • Woher weiß das Skript, welches Feld falsch ist?

How you work

  1. Read the task. The requirements sit on the project page.
  2. Plan first. Sketch elements and functions on paper.
  3. Let AI propose. Check every proposal critically.
  4. Build step by step. Test in the browser after each step.
  5. Upload the file to your GitHub repository. Guide: GitHub & Submission.
  6. Reflect at the end. Print the reflection band for your folder.

The order is a suggestion. Your teacher may combine or drop projects.

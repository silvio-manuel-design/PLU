So arbeitest du

  1. Lies die Aufgabe. Die Anforderungen stehen auf der Projektseite.
  2. Plane zuerst. Skizziere Elemente und Funktionen auf Papier.
  3. Lass die KI vorschlagen. Prüfe jeden Vorschlag kritisch nach.
  4. Baue Schritt für Schritt. Teste nach jedem Schritt im Browser.
  5. Lade die Datei in dein GitHub-Repo hoch. Anleitung: GitHub & Abgabe.
  6. Reflektiere am Ende. Das Reflexions-Band druckst du für deine Mappe.

Die Reihenfolge ist eine Empfehlung. Deine Lehrkraft kann Projekte zusammenfassen oder streichen.

Security Audit

You get insecure code and find the holes. Then you close them. Time: about 120 min.

Your task

The task below contains a page with four security holes. Find every hole and describe it in two sentences. Then write a corrected version. Your report and the file both belong to the submission.

← Back to the projects

Requirements

Only tick a line when your code really does it.

Step by step

  1. Read the insecure code twice. Write down suspicious spots.
  2. Find all four holes. Describe each in two sentences.
  3. Create project-3-security-audit.html. Put your report as an HTML comment at the top.
  4. Rewrite the page: textContent instead of innerHTML, addEventListener instead of onclick.
  5. Remove the eval function completely. It has no business here.
  6. Replace var with let or const.
  7. Test the guestbook with an input like <img src=x onerror=alert(1)>. Nothing may execute.
  8. Let AI double-check your solution. Verify its criticism yourself.
  9. Compare with the requirements and check off everything.

Work with AI

Rule: AI finds holes fast. Your report must still carry your own words.

Starter prompt — copy it and fill in your details:

Three check questions:

  • What makes eval so risky?
  • Why is addEventListener cleaner than onclick?

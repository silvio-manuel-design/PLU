Form Master

Build a signup form that checks everything. Error messages appear right at the field. Time: about 90 min.

Your task

A signup form with four fields: name, email, password and age. On submit, JavaScript checks every field. Found errors appear as text under the field. Only a flawless form is submitted.

← Back to the projects

Requirements

Only tick a line when your code really does it.

Step by step

  1. Create project-2-form-master.html. Build the form with labels and a submit button.

  2. Catch the submit event and stop it with preventDefault.

  3. Check the name field. Show an error message under the field.
  4. Check the email for exactly one @ and a dot after it.
  5. Check the password for at least eight characters.
  6. Check the age for a number greater than zero.
  7. On errors: show messages, block submit. Without errors: show a success message.
  8. Test every error type individually. Then one flawless form.
  9. Ask AI for one improvement. Implement exactly one suggestion.

Work with AI

Rule: AI loves writing validation. You must be able to explain every condition.

Starter prompt — copy it and fill in your details:

Three check questions:

  • Why do we need preventDefault?
  • Why is a simple includes('@') not enough for emails?
  • How does the script know which field is wrong?

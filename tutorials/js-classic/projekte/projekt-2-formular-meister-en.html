PROJECT 2 OF 3 — YOUR TRAINING GROUND

Form Master

Build a signup form that checks everything. Error messages appear right at the field. Time: about 90 min.

Your task

A signup form with four fields: name, email, password and age. On submit, JavaScript checks every field. Found errors appear as text under the field. Only a flawless form is submitted.

You build the form and its validation in a single HTML file. Every field gets its own rule — and you must be able to explain every rule.

← Back to the projects

Allowed tools

Allowed

  • Everything from chapters 01–11 — forms, events and validation with plain JavaScript.

Not allowed

  • Ready-made validation libraries, external plugins, fetch and server code.

Design

Guidelines

  • Error messages appear right under the affected field in a warning colour.
  • Success is visible on the page — without a browser alert.
  • Labels sit above the fields, not beside them — down to 360 px.

Requirements

Only tick a line when your code really does it.

Step by step

  1. 1

    Create the file

    Create project-2-form-master.html. Build the form with labels and a submit button.

  2. 2

    Catch the submit

    Catch the submit event and stop it with preventDefault.

  3. 3

    Name and e-mail

    Check the name field for at least two characters and the e-mail for exactly one @ and a dot after it.

  4. 4

    Password and age

    Check the password for at least eight characters and the age for a number greater than zero.

  5. 5

    Messages and test

    Show error messages under the affected field. Without errors: show a success message. Test every error type separately, then an error-free form.

  6. 6

    Polish

    Ask AI for an improvement. Implement exactly one proposal, then check off all requirements.

Work with AI

Rule: AI loves writing validation. You must be able to explain every condition.

Starter prompt — copy it and fill in your details:

Three check questions

  • Why do we need preventDefault?
  • Why is a simple includes('@') not enough for emails?
  • How does the script know which field is wrong?

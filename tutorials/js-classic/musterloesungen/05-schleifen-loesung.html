🔁 Musterlösung – Kapitel 5: Schleifen

Aufgabe 1: Zähllogik

Schleife A:

  • Läuft 5 Mal (i = 0,1,2,3,4)
  • Ausgabe: 0,1,2,3,4
  • Keine Endlosschleife – klare Abbruchbedingung i < 5

Schleife B:

  • Läuft 5 Mal (j = 5,4,3,2,1)
  • Ausgabe: 5,4,3,2,1
  • Keine Endlosschleife – j wird bei jedem Durchlauf verkleinert

Schleife C – die heimliche Falle:

  • k startet bei 1, wird um 2 erhöht → 1,3,5,7,9,11…
  • k !== 10 ist **immer wahr**, weil k nie 10 wird (ungerade Zahlen!)
  • → Endlosschleife!

✅ Besser: while (k <= 9) oder for (let k = 1; k <= 9; k += 2)

Möglicher Prompt:

Erstelle eine Schleife, die alle ungeraden Zahlen von 1 bis 9 ausgibt.
Verwende eine sichere Abbruchbedingung (z. B. k <= 9), um Endlosschleifen zu vermeiden.
Gib die Zahlen in der Konsole aus.

Aufgabe 2: Countdown

Lösung mit while:

function starteCountdown(start, abbruch) {
  if (start <= abbruch) {
    console.log("Fehler: start muss größer als abbruch sein!");
    return;
  }
  let current = start;
  while (current >= abbruch) {
    console.log(current);
    current--;
  }
}

Testfälle:

  • starteCountdown(10, 5) → 10,9,8,7,6,5 ✅
  • starteCountdown(3, 7) → Fehlermeldung ✅

Warum for weniger geeignet?

Bei for ist die Logik „Zähler von A nach B“ – hier ist der Abbruch aber **dynamisch** (abhänging von zwei Parametern).
while ist **flexibler** bei komplexen oder variablen Abbruchbedingungen.

Möglicher Prompt:

Erstelle eine Funktion starteCountdown(start, abbruch), die von start rückwärts bis abbruch zählt.
Füge eine Fehlerprüfung ein: wenn start <= abbruch, gib eine Fehlermeldung aus.
Verwende eine while-Schleife für maximale Flexibilität.

📝 Musterlösung: Interaktive Todo-Liste

Diese Lösung zeigt eine vollständige, sichere und performante Todo-Liste – mit allen geforderten Funktionen und Best Practices.

Struktur der Lösung

  • ✅ Globale Todo-Liste als Array von Objekten
  • ✅ Lokale Speicherung mit localStorage
  • ✅ Event-Delegation für dynamische Elemente
  • ✅ Sichere Textausgabe (kein raw HTML)
  • ✅ Klare Trennung von Logik und Darstellung

1. Globale Variablen und DOM-Referenzen

Wir speichern die Todos in einem Array und referenzieren die wichtigen DOM-Elemente.

const todos = [];
const todoInput = document.getElementById('todo-input');
const todoList = document.getElementById('todo-list');
const STORAGE_KEY = 'meineTodos';

2. Speichern und Laden mit LocalStorage

Beim Speichern wird das Array in JSON umgewandelt. Beim Laden wird geprüft, ob Daten existieren.

function speichereTodos() {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(todos));
}

function ladeTodos() {
  const gespeichert = localStorage.getItem(STORAGE_KEY);
  if (gespeichert) {
    todos = JSON.parse(gespeichert);
  }
  zeigeTodos();
}

3. Anzeige der Todos – sicher und effizient

Wir leeren die Liste und fügen jedes Todo als <div> mit Checkbox und Button hinzu.
Der Text wird nicht als HTML interpretiert – XSS-Schutz ist gewährleistet.

function zeigeTodos() {
  todoList.innerHTML = '';
  todos.forEach((todo, index) => {
    const todoItem = document.createElement('div');
    todoItem.className = `todo-item ${todo.erledigt ? 'erledigt' : ''}`;
    todoItem.innerHTML = `
      <input type="checkbox" ${todo.erledigt ? 'checked' : ''} data-index="${index}">
      <span class="todo-text">${todo.text}</span>
      <button data-index="${index}">Löschen</button>
    `;
    todoList.appendChild(todoItem);
  });
}

4. Event-Delegation – effizient und wartbar

Ein einziger Listener auf der Todo-Liste handhabt alle Klicks – auch für dynamisch hinzugefügte Todos.

todoList.addEventListener('click', function(e) {
  const index = e.target.dataset.index;
  if (index === undefined) return;

  if (e.target.type === 'checkbox') {
    todos[index].erledigt = e.target.checked;
    speichereTodos();
    zeigeTodos();
  } else if (e.target.tagName === 'BUTTON') {
    todos.splice(index, 1);
    speichereTodos();
    zeigeTodos();
  }
});

5. Initialisierung

Beim Laden der Seite werden die gespeicherten Todos geladen.

document.addEventListener('DOMContentLoaded', ladeTodos);

Warum ist diese Lösung optimal?

  • 🔒 Sicherheit: Kein unkontrolliertes innerHTML mit Benutzereingaben
  • ⚡ Performance: Event-Delegation statt Listener-Flut
  • 💾 Persistenz: Daten bleiben nach Neuladen erhalten
  • 🧼 Lesbarkeit: Klare Funktionen, keine Codewüste
  • 📱 Responsive: Passt sich kleinen Bildschirmen an

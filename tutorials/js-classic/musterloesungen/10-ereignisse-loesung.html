🖱️ Musterlösung – Kapitel 10: Ereignisse & Timing

Aufgabe 1: Event-Listener

Warum kann der Listener nicht entfernt werden?

Der Listener ist eine **anonyme Funktion** – es gibt keine Referenz darauf.
Um removeEventListener zu nutzen, braucht man die **gleiche Funktionsreferenz**.

Verbesserung:

let zaehler = 0;
function handleKlick() {
  zaehler++;
  document.getElementById("ausgabe").textContent = zaehler;
}
const btn = document.getElementById("btn");
btn.addEventListener("click", handleKlick);

// Später entfernen:
// btn.removeEventListener("click", handleKlick);

Event-Delegation:

✅ Bei dynamischen Inhalten (z. B. per DOM hinzugefügte Buttons) weiß man vorher nicht, wie viele es gibt.
→ Man hängt den Listener an ein **übergeordnetes Element** und prüft event.target.
→ Spart Speicher, vermeidet „tote“ Listener.

Möglicher Prompt:

Erstelle einen Klick-Listener für einen Button, der einen Zähler erhöht.
Definiere die Listener-Funktion separat, damit sie später mit removeEventListener entfernt werden kann.
Erkläre, warum anonyme Funktionen nicht entfernt werden können.

Aufgabe 2: Timing

Warum ist das ein Problem?

✅ setInterval läuft **ewig weiter**, auch wenn das Element nicht mehr im DOM ist.
→ Verbraucht CPU, Speicher, Batterie – besonders auf mobilen Geräten.
→ Kann zu Fehlern führen, wenn versucht wird, auf nicht existierende Elemente zuzugreifen.

Lösung mit Start/Stop:

let uhrIntervall = null;

function starteUhr() {
  if (uhrIntervall) return; // schon gestartet
  uhrIntervall = setInterval(() => {
    const el = document.getElementById("uhr");
    if (el) {
      el.textContent = new Date().toLocaleTimeString();
    }
  }, 1000);
}

function stoppeUhr() {
  if (uhrIntervall) {
    clearInterval(uhrIntervall);
    uhrIntervall = null;
  }
}

Möglicher Prompt:

Erstelle Funktionen starteUhr() und stoppeUhr(), die eine Uhr mit setInterval steuern.
Speichere die Intervall-ID in einer globalen Variable.
Füge eine Prüfung ein, ob das Ziel-Element existiert, bevor du es aktualisierst.

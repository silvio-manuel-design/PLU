🧱 Musterlösung – Kapitel 8: Objekte

Aufgabe 1: Objekt vs. Array

Lesbarkeit:

✅ Objekt (Variante B) ist viel lesbarer:
schuelerB.alter ist selbsterklärend – bei schuelerA[1] muss man raten, was Index 1 bedeutet.

Zugriff auf Alter:

  • Array: schuelerA[1] → fehleranfällig (Index-Fehler)
  • Objekt: schuelerB.alter → klar, robust

E-Mail hinzufügen:

  • Array: Reihenfolge stört – muss an letzte Stelle, aber was ist mit anderen Schülern?
  • Objekt: Einfach schuelerB.email = "a@example.com" – keine Reihenfolge nötig!

Möglicher Prompt:

Erstelle ein JavaScript-Objekt für einen Schüler mit den Eigenschaften:
name (string), alter (number), klasse (string), noten (Array of numbers).
Erkläre, warum ein Objekt hier besser geeignet ist als ein Array mit fester Reihenfolge.

Aufgabe 2: this und Methoden

Warum der Fehler?

breite und hoehe sind **Eigenschaften des Objekts** – nicht globale Variablen.
Innerhalb der Methode muss man auf sie mit this.breite und this.hoehe zugreifen.

Verbesserte Methode:

flaeche: function() {
  return this.breite * this.hoehe;
}

Methode info():

info: function() {
  return `Rechteck ${this.breite}×${this.hoehe} = ${this.flaeche()} cm²`;
}

Möglicher Prompt:

Erstelle ein Objekt "rechteck" mit breite, hoehe und Methoden flaeche() und info().
Verwende this.breite und this.hoehe in den Methoden.
Gib in info() einen formatierten String zurück.

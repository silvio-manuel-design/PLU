📦 Musterlösung – Kapitel 7: Funktionen

Aufgabe 1: Rückgabewert vs. Seiteneffekt

Unterschied:

  • Variante A (Seiteneffekt): Verändert das übergebene Array direkt → original wird geändert.
  • Variante B (reine Funktion): Gibt ein **neues Array** zurück → original bleibt unberührt.

Anwendungsbeispiele:

  • ✅ **Seiteneffekt sinnvoll**: Todo-Liste im DOM – du willst das Original aktualisieren.
  • ✅ **Reine Funktion sinnvoll**: Berechnung von Zwischenergebnissen – du willst das Original erhalten.

Testergebnis:

const original = ["Apfel"];
fuegeHinzuA(original, "Banane");     // original = ["Apfel", "Banane"]
const neueListe = fuegeHinzuB(original, "Orange"); // neueListe = ["Apfel", "Banane", "Orange"]
// original bleibt = ["Apfel", "Banane"]

Möglicher Prompt:

Erstelle eine Funktion fuegeHinzu(liste, element), die ein neues Array zurückgibt,
ohne das Original-Array zu verändern.
Verwende den Spread-Operator [...liste, element].

Aufgabe 2: Scope und Closure

Warum bleibt zaehler erhalten?

Die innere Funktion („Closure“) **merkt sich ihre Umgebung** – also die Variable zaehler – auch nachdem zaehlerErzeugen() beendet ist.

Zweiter Zähler:

const zaehler2 = zaehlerErzeugen();
console.log(zaehler2()); // → 1
console.log(zaehler1()); // → 3 (unabhängig!)

✅ Jeder Aufruf von zaehlerErzeugen() erzeugt einen **eigenen Scope** mit eigenem zaehler.

Warum ist das Closure?

Die innere Funktion **„schließt“** („closes over“) die Variable zaehler aus ihrem äußeren Scope ein – daher der Name **Closure**.

Möglicher Prompt:

Erstelle eine Funktion zaehlerErzeugen(), die eine Closure zurückgibt,
die bei jedem Aufruf einen internen Zähler erhöht und zurückgibt.
Erkläre, warum jeder erzeugte Zähler unabhängig ist.

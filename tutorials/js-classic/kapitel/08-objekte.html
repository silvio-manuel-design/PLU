Kapitel 08

Objekte: Daten mit Namen

Echte Dinge beschreiben: Eigenschaften sammeln, lesen und verändern.

Einstieg 1 Anlegen 2 Verändern 3 Methoden 4 Arrays von Objekten ✓ Checkliste Quiz

ERST MAL VERSTEHEN

Stell dir einen Steckbrief vor. Name: Ada. Alter: 16. Klasse: 2a. Alles auf einer Karte. Jedes Feld hat eine Beschriftung.

Du brauchst nicht fünf Zettel für eine Person. Eine Karte reicht. Und du findest alles sofort: „Feld Alter."

Ein Objekt ist genau das für dein Programm: Eine Sammlung von beschrifteten Werten. Ein Ding — mit allem, was dazugehört, an einem Ort.

WÖRTER, DIE DU JETZT LERNST

Objekt / object

Beschriftete Werte zu EINEM Ding, in geschweiften Klammern.

Alltag: wie ein Steckbrief.

const schueler = { name: "Ada" };

Eigenschaft (Property) / property

Ein beschriftetes Feld des Objekts.

Alltag: ein Feld auf dem Steckbrief.

alter: 16

Schlüssel (Key) / key

Die Beschriftung des Felds.

Alltag: die Aufschrift „Alter" auf dem Formular.

name

Methode / method

Eine Funktion, die IN einem Objekt lebt.

Alltag: eine Fähigkeit der Person — „Ada kann rechnen."

begruesse() { … }

Objekt anlegen und Eigenschaften lesen

Bisher: Variablen für einzelne Werte, Arrays für Listen. Aber die Welt besteht aus Dingen, nicht aus Listen. Objekte beschreiben Dinge.

Ein Objekt sammelt beschriftete Werte in { schluessel: wert, … }. Gelesen wird mit Punkt (.name) oder Klammer (["name"]). Und Objekte können in Objekten wohnen.

Playground

Probier es direkt aus — dein erster eigener Code läuft hier im Browser:

playground.js

Deine Aufgabe: Gib eine dritte Eigenschaft deines Objekts in der Konsole aus — z. B. schueler.lieblingsfach.

Typische Fehler

Leerzeichen im Schlüssel

fach note: "MT" ohne Anführungszeichen ist ein Syntaxfehler. Mit Leerzeichen braucht der Schlüssel Quotes — besser: Unterstriche.

Punkt vs. Klammer falsch

Steht der Schlüssel in einer Variablen, geht nur die Klammer: obj[key]. Der Punkt verlangt einen festen Namen.

Komma-Panik

Ein Komma nach dem letzten Eintrag ist erlaubt (trailing comma) — kein Fehler. Aber zwischen den Einträgen ist es Pflicht.

Punkt-Kette ohne Verständnis

kurs.lehrer.name liest sich außen nach innen: kurs → lehrer → name. Jeder Punkt öffnet das nächste Ding.

Profi-Tipp

Klammer-Notation für dynamische Schlüssel: obj[key] — wenn der Schlüssel in einer Variablen steht, geht nur die Klammer.

Objekte verändern: Werte setzen, löschen, hinzufügen

Steckbriefe ändern sich: Jemand zieht um, wird älter, bekommt ein neues Fach. Objekte sind lebendig.

Werte überschreibst du einfach mit =, neue Eigenschaften legst du an, indem du sie setzt — und delete entfernt ein Feld.

Typische Fehler

„const verbietet Änderungen"

Bei Objekten sperrt const nur die REFERENZ — der Inhalt ist frei veränderbar. Das verwirrt am Anfang jeden.

delete übernutzen

Wer ständig Felder löscht und wieder anlegt, verliert die Form. Struktur anpassen statt Felder wegräumen.

Leerzeichen-Feld mit Punkt

obj.fach note bricht sofort — Felder mit Leerzeichen nur per Klammer: obj["fach note"].

Objekt bei const neu zuweisen

schueler = { … } auf eine const-Variable ist ein Fehler — die Referenz ist fest. Inhalt ändern geht, neu setzen nicht.

Profi-Tipp

const bei Objekten heißt: DIESES Objekt bleibt es — nicht: sein Inhalt friert ein. Das verwirrt am Anfang jeden.

DIDAKTISCHE PAUSE

Überall um dich herum sind Objekte: Dein Handy hat Eigenschaften (Farbe, Speicher) und Methoden (anrufen, fotografieren). Dein Fahrrad, dein Stift, deine Tasche. Programmieren mit Objekten heißt: Die Welt so beschreiben, wie sie wirklich ist.

Methoden: Funktionen im Objekt

Ein Ding ohne Fähigkeiten ist nur Datenspeicher. Methoden machen Objekte lebendig: Sie können Dinge TUN.

Eine Methode ist eine Funktion als Eigenschaft — aufgerufen mit obj.methode(). this siehst hier nur als Vorschau: In einer Methode zeigt es auf das eigene Objekt.

Typische Fehler

Methode ohne () aufrufen

greeter.begruesse ist die Funktion selbst, kein Ergebnis — die Klammern führen sie aus.

this anfangs erzwingen

Erst das Objekt-Muster verstehen, dann this. Wer zu früh mit this jongliert, kämpft gegen Windmühlen.

Methode außerhalb aufrufen

begruesse("Ada") allein existiert nicht — die Methode lebt IM Objekt und braucht ihren Besitzer davor.

Pfeilfunktion + this

Methoden als Arrow-Funktion zu schreiben, bricht this — merk dir nur: normale Funktionsschreibweise in Objekten.

Profi-Tipp

this ist für später — merk dir nur: IN einer Methode zeigt this auf das Objekt, in dem sie lebt. Mehr brauchst du jetzt nicht.

Arrays von Objekten: Die echten Daten

Eine Klasse ist eine Liste von Schülern. Jeder Schüler ist ein Objekt. Arrays von Objekten sind DAS Datenformat des echten Lebens.

Array + Objekt + for...of: Die Liste durchläufst du mit der Schleife aus Kapitel 06, jedes Element ist ein Steckbrief aus diesem Kapitel.

Typische Fehler

[1] liefert den Namen?

klasse[1] ist ein ganzes Objekt — erst .name holt den Namen daraus. Erst die Klammer, dann der Punkt.

JSON-Syntax mit =

In Objekten heißt es name: "Ada" — Doppelpunkt, nicht Gleichheitszeichen. Das = kommt aus JSON-Vorlagen.

Klammern verwechselt

Array = eckig [ ], Objekt = geschweift { }. Im Wechsel: [{ … }, { … }].

„Alle Objekte brauchen gleiche Felder"

JavaScript erlaubt unterschiedliche Felder — sauberer Code hält sie trotzdem einheitlich. Einheitlichkeit gewinnt.

Profi-Tipp

Arrays von Objekten + for...of — mit diesem einen Muster kannst du fast jede echte Datenaufgabe lösen. Es ist der Dreh- und Angelpunkt des Kurses.

Check: Kannst du das schon?

Array für die Liste, Objekt für die Person, for...of für den Durchlauf.

Zusammenfassung

  • Objekt = beschriftete Werte in {} — wie ein Steckbrief.
  • Punkt für feste Schlüssel, Klammer für dynamische.
  • const sperrt die Referenz, nicht den Inhalt.
  • Methoden = Fähigkeiten des Objekts, aufgerufen mit ().
  • Array von Objekten + for...of = das Standardmuster echter Daten.

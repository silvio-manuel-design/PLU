Kapitel 06

Arrays: Listen & Sammlungen

Viele Werte, eine Variable: Listen aufbauen, durchlaufen und auswerten.

ERST MAL VERSTEHEN

Du gehst einkaufen. Du schreibst eine Liste: Brot, Milch, Eier. Alles auf einem Blatt. Durchnummeriert.

Du musst nicht drei Zettel mitschleppen. Ein Blatt reicht. Die Nummern helfen dir: „Nummer 2 von der Liste."

Ein Array ist genau das für dein Programm: Eine Liste von Werten auf einem „Blatt" — durchnummeriert und bereit für die Schleife aus Kapitel 05.

WÖRTER, DIE DU JETZT LERNST

Array / array

Eine nummerierte Liste von Werten in einer Variable.

Alltag: wie die Einkaufsliste auf einem Blatt.

const einkauf = ["Brot", "Milch"];

Index / index

Die Nummer eines Elements. Beginnt bei 0!

Alltag: wie „Nummer 2 auf der Liste" — bei Programmen zählt die 0 als erste.

einkauf[0]

Element / element

Ein einzelner Wert in der Liste.

Alltag: ein Punkt auf der Einkaufsliste.

"Milch"

Länge (length) / length

Wie viele Elemente die Liste hat.

Alltag: die Zahl deiner Listenpunkte.

einkauf.length

Array anlegen und Elemente lesen

Bisher lag in jeder Variable ein Wert. Echte Daten kommen nie einzeln: Notenlisten, Spielstände, Warenkörbe. Arrays holen dich da ab.

Ein Array legst du mit eckigen Klammern an: ["Brot", "Milch"]. Der Zugriff läuft über den Index in eckigen Klammern — und der beginnt bei 0, nicht bei 1. length liefert die Anzahl der Elemente.

Typische Fehler

„Der Index beginnt bei 1"

Nein — er beginnt bei 0. einkauf[1] ist das ZWEITE Element. Diese Umstellung kostet am Anfang jeden Nerven.

Punkt statt Klammer

einkauf.1 ist ein Syntaxfehler — Zahlen als Index brauchen eckige Klammern: einkauf[1].

length und Index verwechselt

length zählt ab 1 (4 Elemente), der Index ab 0 (letzter Index: 3). Deshalb: letztes Element = length - 1.

Zugriff jenseits der Liste

einkauf[10] liefert undefined — kein Fehler, aber gefährlich. Bei unbekannten Listen immer erst length prüfen.

Profi-Tipp

Das letzte Element ist arr[arr.length - 1] — dieser Ausdruck kommt in echtem Code ständig vor. Merk ihn dir.

Arrays mit Schleifen durchlaufen

Der ganze Sinn einer Liste: Sie Punkt für Punkt abarbeiten. Die for-Schleife aus Kapitel 05 trifft hier auf ihre Bestimmung.

Die klassische for mit i < arr.length gibt dir den Index — perfekt, wenn du die Position brauchst. Wenn nur die Werte zählen, ist for...of die bequemere Variante.

Typische Fehler

Off-by-one am Ende

i <= noten.length greift einmal zu weit → undefined beim letzten Durchlauf. Die Bedingung heißt <, nicht <=.

Index aus for...of erwarten

for...of liefert die WERTE, keine Nummern. Brauchst du die Position, nimm die klassische for-Schleife.

Array in der Schleife verkleinern

Elemente entfernen, während du darüber läufst, verschiebt alle Indexe — die Schleife rutscht dann an Elementen vorbei.

noten[i] vergessen

console.log(i) gibt nur die Nummer aus, nicht den Wert. Erst noten[i] holt das Element.

Profi-Tipp

Brauchst du den Index? Klassische for. Geht's nur um die Werte? for...of. Diese eine Entscheidung macht Arrays lesbar.

DIDAKTISCHE PAUSE

Arrays gibt es im echten Leben überall: Der Stundenplan ist ein Array aus Stunden. Dein Klassenbuch ist ein Array aus Einträgen. Deine Playlist ist ein Array aus Songs. Ab jetzt wirst du keine Liste mehr sehen, ohne an Arrays zu denken.

Arrays verändern: push, pop, includes

Listen sind lebendig: Etwas dazukaufen, etwas streichen, prüfen, ob etwas schon draufsteht.

push() hängt hinten an, pop() entfernt hinten (und gibt das Element zurück). includes() prüft, ob ein Wert drin ist; indexOf() findet die Position (-1 = nicht gefunden).

Typische Fehler

„push erzeugt ein neues Array"

Nein — push verändert das bestehende Array. Eine Kopie bekommst du mit anderen Methoden (dazu später mehr).

includes ohne Klammern

einkauf.includes (ohne ()) ist die Funktion selbst, nicht das Ergebnis. Aufrufen nicht vergessen.

pop() auf leeres Array

Liefert undefined — kein Fehler, aber prüf lieber vorher length, wenn die Liste leer sein kann.

indexOf mit Truthiness

if (einkauf.indexOf("Brot")) ist bei Index 0 FALSH — 0 ist falsy! Richtig: !== -1 vergleichen oder gleich includes nehmen.

Profi-Tipp

indexOf("x") !== -1 ist dasselbe wie includes("x") — includes ist die moderne, lesbare Version.

Demo: Würfel-Statistik (Arrays in Aktion)

Ein Würfel wird 100 Mal geworfen. Welche Zahl kam wie oft? Mit einem Array ist das zehn Zeilen.

Das Muster heißt Zähler-Array: Ein Array mit sechs Zählern (Index 0 bis 5). Die gewürfelte Zahl bestimmt, welcher Zähler hochgeht — counts[wurf - 1]++. Keine sechs Einzelvariablen nötig.

Würfel-Statistik

Index = Würfelzahl − 1. Beobachte, wie gleichmäßig sich die Häufigkeiten verteilen.

Typische Fehler

Sechs Variablen statt Array

wuerfel1, wuerfel2, … skaliert nicht — bei 100 Werten schreibst du 100 Zeilen. Das Zähler-Array ersetzt sie alle.

Index 0 ungenutzt verwirrt

Beim Zähler-Array für Würfelzahlen liegt Zahl 1 auf Index 0. Wer Index = Zahl denkt, zählt daneben.

Zufallszahl falsch skalieren

Math.random() * 6 + 1 ohne Runden ergibt Kommazahlen — immer mit Math.floor() zu einer echten Zahl machen.

Array nicht mit 0 füllen

Ein leeres Array liefert undefined beim ersten ++ — das Zähler-Array startet mit sechs Nullen.

Profi-Tipp

Das Zähler-Array ist das wichtigste Array-Muster überhaupt — damit zählst du Treffer, Buchstaben, Klicks, alles.

Zusammenfassung

  • Array = nummerierte Liste in einer Variable, Index beginnt bei 0.
  • length zählt ab 1 — letztes Element: arr[arr.length-1].
  • for = mit Index, for...of = nur Werte.
  • push/pop verändern das Array; includes/indexOf prüfen es.
  • Das Zähler-Array zählt alles: Treffer, Häufigkeiten, Ergebnisse.

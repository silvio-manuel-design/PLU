FIRST, LET'S UNDERSTAND

You go shopping. You write a list: bread, milk, eggs. Everything on one piece of paper. Numbered.

You don't carry three notes around. One paper is enough. The numbers help you: “Number 2 on the list.”

An array is exactly that for your program: a list of values on one “paper” — numbered and ready for the loop from chapter 05.

WORDS YOU'RE LEARNING NOW

Array / Array

A numbered list of values in one variable.

Everyday: like the shopping list on one piece of paper.

const shopping = ["bread", "milk"];

Index / Index

The number of an element. It starts at 0!

Everyday: like „number 2 on the list" — in programs, 0 counts as first.

shopping[0]

Element / Element

A single value in the list.

Everyday: one item on the shopping list.

"milk"

Length / Länge

How many elements the list has.

Everyday: the count of your list items.

shopping.length

Creating arrays and reading elements

So far every variable held one value. Real data never comes alone: grade lists, game scores, shopping carts. Arrays catch you there.

You create an array with square brackets: ["bread", "milk"]. Access works via the index in square brackets — and it starts at 0, not 1. length returns the number of elements.

Typical mistakes

„The index starts at 1"

No — it starts at 0. shopping[1] is the SECOND element. This shift costs everyone nerves at first.

Dot instead of brackets

shopping.1 is a syntax error — numbers as an index need square brackets: shopping[1].

Confusing length and index

length counts from 1 (4 elements), the index from 0 (last index: 3). That's why the last element is length - 1.

Reading past the list

shopping[10] returns undefined — no error, but dangerous. With unknown lists, check length first.

Pro tip

The last element is arr[arr.length - 1] — this expression appears constantly in real code. Memorise it.

Looping through arrays

The whole point of a list: working through it item by item. The for loop from chapter 05 meets its destiny here.

The classic for with i < arr.length gives you the index — perfect when you need the position. When only the values matter, for...of is the more comfortable variant.

Typical mistakes

Off-by-one at the end

i <= grades.length reaches one step too far → undefined on the last pass. The condition is <, not <=.

Expecting an index from for...of

for...of delivers the VALUES, no numbers. If you need the position, use the classic for loop.

Shrinking the array inside the loop

Removing elements while iterating shifts every index — the loop then skips over items.

Forgetting grades[i]

console.log(i) only prints the number, not the value. Only grades[i] fetches the element.

Pro tip

Need the index? Classic for. Only the values? for...of. This one decision makes arrays readable.

TEACHING BREAK

Arrays are everywhere: your timetable is an array of lessons, your playlist an array of songs. From now on you won't see a list without thinking of arrays.

Changing arrays: push, pop, includes

Lists are alive: add something, cross something off, check whether something is already on it.

push() appends at the end, pop() removes at the end (and returns the element). includes() checks whether a value is inside; indexOf() finds the position (-1 = not found).

Typical mistakes

„push creates a new array"

No — push changes the existing array. A copy needs other methods (more on that later).

includes without parentheses

shopping.includes (without ()) is the function itself, not the result. Don't forget to call it.

pop() on an empty array

Returns undefined — no error, but better check length first when the list can be empty.

indexOf with truthiness

if (shopping.indexOf("bread")) is FALSE at index 0 — 0 is falsy! Compare properly with !== -1 or just use includes.

Pro tip

indexOf("x") !== -1 is the same as includes("x") — includes is the modern, readable version.

Demo: Dice statistics (arrays in action)

A die is rolled 100 times. Which number came up how often? With an array, that's ten lines.

The pattern is called a counter array: an array with six counters (index 0 to 5). The rolled number decides which counter goes up — counts[roll - 1]++. No six separate variables needed.

Dice statistics

Index = die value − 1. Watch how evenly the frequencies spread.

Typical mistakes

Six variables instead of an array

dice1, dice2, … doesn't scale — with 100 values you write 100 lines. The counter array replaces them all.

Confusion about index 0

In a counter array for die values, number 1 lives at index 0. If you think index = value, you count beside the mark.

Badly scaled random numbers

Math.random() * 6 + 1 without rounding gives decimals — always turn it into a real number with Math.floor().

Not filling the array with 0

An empty array returns undefined on the first ++ — the counter array starts with six zeros.

Pro tip

The counter array is the most important array pattern of all — it counts hits, letters, clicks, everything.

Summary

  • Array = numbered list in one variable, index starts at 0.
  • length counts from 1 — last element: arr[arr.length - 1].
  • for = with index, for...of = values only.
  • push/pop change the array; includes/indexOf check it.
  • The counter array counts everything: hits, frequencies, results.

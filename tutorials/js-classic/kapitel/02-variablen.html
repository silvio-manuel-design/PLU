Variablen & Datentypen

Merken, was das Programm weiß: Werte benennen, speichern und richtig lesen.

ERST MAL VERSTEHEN

Du hast einen Spind in der Schule. Auf dem Spind steht dein Name. Du legst etwas hinein. Später holst du es wieder heraus.

Dein Nachbar hat seinen eigenen Spind. Sein Name steht drauf. Deine Sachen und seine Sachen vermischen sich nie.

Das ist eine Variable: ein benannter Platz, an dem das Programm etwas aufbewahrt. Der Name gehört zum Platz. Der Inhalt kann wechseln.

WÖRTER, DIE DU JETZT LERNST

Variable / variable

Ein benannter Platz im Speicher des Programms.

Alltag: wie dein Spind mit Namensschild.

let punkte = 0;

Wert / value

Das, was gerade in der Variable liegt.

Alltag: das, was heute in deinem Spind ist.

punkte = 10;

Text (string) / text (string)

Ein Wert aus Buchstaben. Steht in Anführungszeichen.

Alltag: wie ein Zettel mit einer Botschaft.

let name = "Ada";

Zahl (number) / number

Ein Wert, mit dem man rechnen kann.

Alltag: wie der Stand deines Guthabens.

let alter = 16;

Variablen deklarieren: let & const

Ein Programm ohne Variablen ist ein Rechner ohne Memory-Taste: Es kann nichts behalten. Variablen geben Werten einen Namen — und Namen sind das wichtigste Werkzeug beim Programmieren.

Eine Variable ist ein benannter Speicherplatz. let verwendest du für Werte, die sich ändern; const für Werte, die konstant bleiben. Deklariert wird mit einem Schlüsselwort, zugewiesen mit = — gesprochen: „wird".

Merke: = ist keine Gleichung, sondern ein Befehl: „Nimm das auf der rechten Seite und packe es in den Namen auf der linken."

Punkte-Zähler

0

Genau das passiert in deinem Script: Eine Variable, die sich bei jedem Klick neu zuweisen lässt.

Typische Fehler

„= ist ein Gleichheitszeichen"

Falsch — es ist eine Zuweisung. Sprich „punkte wird 10", nicht „punkte ist gleich 10". Die Richtung ist entscheidend.

Ohne Schlüsselwort deklarieren

punkte = 10; ohne let/const erzeugt eine implizit globale Variable — im Strict Mode ein Fehler, sonst eine tickende Zeitbombe.

const falsch verstehen

Bei Objekten und Arrays ist der Inhalt durchaus änderbar — nur die Referenz ist fest. const liste = [] darfst du füllen, nicht neu zuweisen.

Namen mit Leerzeichen & Sonderzeichen

let meine punkte oder Umlaute/Sonderzeichen im Namen führen zu Fehlern oder Ärger. Regel: Kleinbuchstaben, Ziffern, Unterstriche — und sprechende Namen.

Profi-Tipp

Erst const verwenden. Erst wenn die Zeile wirklich neu zugewiesen werden muss, auf let wechseln — das verhindert halb die Kapitel-03-Fehler.

Datentypen kennen: string, number, boolean, undefined

JavaScript sortiert jeden Wert automatisch in einen Typ. Wer die Typen nicht kennt, wundert sich, warum '7' + 3 plötzlich '73' ergibt.

Die Kern-Typen: string (Text in Anführungszeichen), number (ganze und Kommazahlen), boolean (true/false) und undefined (noch nichts zugewiesen). Mit typeof prüfst du den Typ eines Werts — direkt im Playground unten testbar.

Typische Fehler

Gemischte Anführungszeichen

"Hallo' bricht: Anfang und Ende eines Strings müssen zum selben Zeichentyp gehören — beide " oder beide '.

"7" + 3 = "73"

Ein String plus eine Zahl ergibt Verkettung, keine Rechnung. JavaScript rechnet nur, wenn beide Seiten Zahlen sind — vor dem Rechnen umwandeln.

Komma statt Punkt

7,5 ist in JavaScript kein Komma — es entsteht ein unerwarteter Wert. Kommazahlen schreibt man mit Punkt: 7.5.

undefined mit null verwechseln

undefined heißt: nie zugewiesen. null heißt: bewusst leer gesetzt. Zwei verschiedene Aussagen, zwei verschiedene Werte.

Profi-Tipp

Kommazahlen: 0.1 + 0.2 === 0.3 ist false (Rundungsfehler im Binärsystem). Bei Geldbeträgen in Cent rechnen — 199 + 1 statt 1.99 + 0.01.

DIDAKTISCHE PAUSE

Variablen gibt es übrigens nicht nur im Computer: Dein Handy merkt sich deine PIN als Variable, dein Browser dein Passwort. Der Unterschied: Ein Programm vergisst ALLES, wenn es endet — darum gibt es Datenbanken (Kapitel für den Sommer: Backend).

Werte einlesen mit prompt()

Bisher schreiben wir Werte selbst in den Code. Programme werden erst lebendig, wenn der USER Werte eingibt.

prompt("Wie heißt du?") öffnet ein Eingabefenster und liefert den eingegebenen Text zurück — immer als String, auch bei Zahlen! Willst du damit rechnen, wandele mit Number() um.

Begrüßungs-Demo

prompt() liefert immer einen String — auch, wenn du eine Zahl eintippst.

Typische Fehler

prompt-Ergebnis direkt rechnen

prompt("Alter?") + 1 ergibt "161" statt 17: Der String wird angehängt, nicht addiert. Erst Number(), dann rechnen.

Abbrechen ignorieren

Klickt jemand „Abbrechen", liefert prompt() null. Wer das nicht prüft, rechnet später mit null und wundert sich.

Sensible Daten abfragen

prompt() zeigt den Text im Klartext und speichert nichts sicher — nie für Passwörter oder private Daten verwenden. Nur Lernzwecke.

NaN übersehen

Number("abc") ergibt NaN — und NaN === NaN ist (irritierenderweise) false. Prüfen mit isNaN(wert).

Profi-Tipp

NaN heißt „Not a Number" — es IST trotzdem ein number-Typ. JavaScript ist voller solcher Überraschungen; typeof NaN === 'number'.

Template-Literals & Ausgabe bauen

Strings zusammenzimmern mit + wird bei längeren Texten unleserlich. Template-Literals sind der moderne Standard.

Statt Anführungszeichen setzt du Backticks (diese rückwärts geneigten Hochkommas). Innerhalb von ${'{'}…} setzt du Werte, Variablen und sogar Rechnungen direkt in den Text.

Playground

Probier es direkt aus — dein erster eigener Code läuft hier im Browser:

playground.js

Deine Aufgabe: Erweitere die Ausgabe um eine Zeile 'Note: 1' — geschrieben als Template-Literal mit eingesetzter Variable.

Typische Fehler

Normale Anführungszeichen mit ${}…

"Hallo ${name}" mit geraden Anführungszeichen ersetzt nichts — ${} funktioniert ausschließlich in Backticks.

Backtick-Taste nicht finden

Auf deutscher Tastatur liegt der Backtick links neben der Backspace-Taste, unter Esc — oft erst nach Leertaste sichtbar. (`´ ≠ `!)

Verschachtelte Anführungszeichen

Ohne Template-Literal kollidieren "Er sagte "Hallo"". Backticks lösen das elegant: `Er sagte "Hallo"`.

${} vergessen

`Note: punkte` gibt wörtlich „Note: punkte" aus — ohne ${} ist alles Text. Die geschweiften Klammern sind der Platzhalter-Befehl.

Profi-Tipp

Template-Literals können auch rechnen: `${'{'}preis * 1.2} €` — Rechnen direkt im Text. Für alles Komplexere: vorher in eine Variable.

Check: Kannst du das schon?

const wo möglich, Number() vor jeder Rechnung, Template-Literal für die Ausgabe — das ist das volle Kapitel in 8 Zeilen.

Zusammenfassung

  • Variablen = benannte Speicherplätze: let für Änderbares, const für Festes.
  • = weist zu, es ist KEIN Gleichheitszeichen.
  • Die Kern-Typen: string, number, boolean, undefined — typeof prüft sie.
  • prompt liefert immer string → vor dem Rechnen Number() verwenden.
  • Template-Literals (Backticks + ${}) bauen lesbare Texte.

KI-Prompt-Training

Du arbeitest im Kurs grundsätzlich mit KI-Assistenten. Lern, gute Prompts zu schreiben — das ist die wichtigste neue Fähigkeit.

Schlechter Prompt „Erklär mir Variablen."

Warum schlecht?

Vage: kein Ziel, kein Level, kein Kontext. Die Antwort wird ein allgemeines Kapitel aus einem Lehrbuch.

Guter Prompt „Baue mit der KI einen Taschenrechner-Dialog: Zwei Zahlen einlesen, alle vier Grundrechnungsarten ausgeben. Prüfe die KI-Ausgabe: Sind die Typen richtig? Sind die Template-Literals sauber?"

Warum gut?

Aufgabe, Umfang und Prüfkriterien stehen drin — und die Nachfrage „Sind die Typen richtig?" trainiert genau das Kapitelwissen.

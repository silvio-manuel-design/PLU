💡 Entdecke JavaScript

Die Sprache, die Webseiten zum Leben erweckt.

🧠 Was ist JavaScript?

JavaScript (JS) ist eine universelle Programmiersprache, die ursprünglich entwickelt wurde, um Webseiten interaktiv zu machen. Während HTML die Struktur und CSS das Design einer Webseite definiert, sorgt JavaScript für das Verhalten – also für Dynamik, Reaktionen auf Benutzeraktionen und Kommunikation mit Servern.

💡 Merke: Ohne JavaScript wäre das Web statisch – mit JavaScript wird es lebendig!

🛠️ Wozu braucht man JavaScript?

  • Formulare validieren, bevor sie abgeschickt werden
  • Inhalte dynamisch nachladen (z. B. bei Suchvorschlägen)
  • Animationen und interaktive Menüs steuern
  • Spiele, Taschenrechner oder To-Do-Listen bauen
  • Mit modernen Frameworks ganze Webanwendungen erstellen (React, Vue, etc.)

↔️ Client-seitig vs. Server-seitig

Normalerweise läuft JavaScript im Browser (Client-seitig) – also auf dem Gerät der Besucherin. Mit Node.js kann JavaScript aber auch auf dem Server ausgeführt werden. In diesem Tutorial konzentrieren wir uns zunächst auf die client-seitige Verwendung.

„Stell dir vor, der Browser ist ein Restaurant-Gast (Client), und der Server ist die Küche. JavaScript im Browser entscheidet, was auf deinem Tisch passiert (z. B. Menü anzeigen). JavaScript auf dem Server (z. B. mit Node.js) entscheidet, was in der Küche passiert (z. B. Bestellung verarbeiten).“

⚠️ Achtung: Client-seitiges JS kann nicht auf Dateien auf dem Server zugreifen – aus Sicherheitsgründen!

🎯 Lernziele dieses Tutorials

Am Ende dieses Kurses kannst du:

  • Grundlegende JS-Syntax beherrschen (Variablen, Operatoren, Bedingungen)
  • Funktionen schreiben und wiederverwenden
  • Arrays und Objekte zur Datenverwaltung nutzen
  • Das DOM manipulieren – Inhalte dynamisch ändern
  • Auf Benutzeraktionen reagieren (Klicks, Tastatur)
  • KI als Denkpartner nutzen – nicht als Code-Lieferant

Was ist JavaScript — und warum verändert es deine Website?

Du kennst HTML und CSS: damit baust du Websites, die für alle gleich aussehen. JavaScript ist der Schritt, der sie zum Leben erwachen lässt.

Eine Sprache, die im Browser lebt

JavaScript ist eine clientseitige Skriptsprache: Der Code läuft direkt im Browser deiner Besucher:innen — ohne Server, ohne Warten, ohne Installation. Jede moderne Website setzt darauf.

Skript- oder Programmiersprache?

Ein Skript arbeitet ein anderes Programm Schritt für Schritt an: Dein Browser liest deinen JavaScript-Code Zeile für Zeile und führt ihn sofort aus. Praktisch kannst du damit alles bauen, was eine klassische Programmiersprache kann.

Von statisch zu dynamisch

HTML und CSS liefern statische Seiten — jede Besucherin sieht dasselbe. JavaScript macht Seiten dynamisch: Sie reagieren auf Klicks, rechnen mit Eingaben und verändern Inhalte im laufenden Betrieb — wie eine App.

What is JavaScript — and why does it change your website?

You know HTML and CSS: they build websites that look the same for everyone. JavaScript is the step that brings them to life.

A language that lives in the browser

JavaScript is a client-side scripting language: your code runs directly in your visitors' browser — no server, no waiting, no installation. Every modern website relies on it.

Scripting language or programming language?

A script instructs another program step by step: your browser reads your JavaScript code line by line and executes it immediately. In practice, you can build anything a classical programming language can.

From static to dynamic

HTML and CSS deliver static pages — every visitor sees the same. JavaScript makes pages dynamic: they react to clicks, compute with input and change content on the fly — like an app.
